2026-09-30 用户选定方案1，并要求增加类目分类与自定义时间。当前预览只保留均衡对比看板；其他四版已从活动代码和界面移除，历史代码与证据保留在Git。正式系统接线仍等待F公共契约冻结及P/A等接口验收，当前页面全部为合成数据。

## 当前功能

- 顶部墨绿主菜单＋横向网店栏目，字体/字号/色调沿用系统规范。
- 店铺/平台对比、平台、来源、日周月、覆盖，以及新增的类目分类：全部、商用设备、炊事设备、配件、未知类目。
- 类目联动摘要、趋势、效率、排名、结构和演示详情；类目变化重置分页，返回详情保留范围。商品详情缺对应分类时显示缺源，不以其他类目商品替代。
- 本期、基期分别自定义；顶部统计周期也可打开本期选择器。双月日历、13个原系统快捷日期、端点点击/鼠标跨月拖选、手工输入、清空草稿、取消/确定；仅确定时更新范围。
- 合成数据日期范围为2025-01-01至2026-09-30，单期含端点最多366天。未来、无效、倒序或超长草稿不能确定。两期实际日期和天数始终展示，基期可单独设置。

## 数据边界

分类夹具使用固定合成分类事实，保留整数/负值/缺失及完整分类加总守恒。该演示实现不得用于生产按店铺总额分摊类目业绩：真实分类筛选须消费商品级分类、精确ERP/推广映射及覆盖的已验收聚合接口。跨平台字典未验证时不可按同名类目匹配。

合成成交商品计数按完整平台日源和分类成交件数约束；零成交返回0、缺来源返回null。金额、毛利、归因口径仍分开；两期完整候选先配对再排名，比率按分子分母合计。当前详情只是隔离演示，未接正式专题/路由。

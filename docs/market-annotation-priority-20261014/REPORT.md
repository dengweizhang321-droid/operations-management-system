# 市场 AI 分类优先与持续补位

状态：开发与隔离验证完成，共覆盖 70 个 PG 定向用例和 156 个 TypeScript 用例；交付提交与制品见 DELIVERY.md，尚未上线。

## 行为与边界

- A：缺少 Prompt 内有效分类，一张图、一次模型 POST 同时提取分类与价格。B：已有有效分类，固定原分类，仅提取价格。领取先选当前可执行 A；A 只有在途项时立即领取 B。新 A 在下一个空闲位置优先，已在途 B 不取消。两类共用原任务并发、供应商退避和多任务公平配额，没有修改模型、供应商、全局参数或正式并发设置。
- 复用原 Django 持久队列、协调租约、单图租约和完成回执。派发准备后领取窗口从 10 秒扩为有界 70 秒／最多 200 次；完成即补位，普通图片失败继续领取，通道冷却仍由 Django 决定。时间片结束后收尾在途，重新检查可执行队列；有工作立即唤醒，空闲才等待原 60 秒。标注与其他维护队列同步启动。边界收尾及维护本身仍可能产生空闲，不宣称永远保持满载。
- 恢复在同一事务先隔离历史过期租约，再允许剩余项运行；无可运行项返回实际暂停状态。既有未知项保留失败次数／隔离记录，不重置或重放。模型完成后的回执重试不重复推理；跨月同图仍原子扩散，B 类兄弟记录的分类保留。
- 使用既有审计表事务性保存模式／固定分类／新完成事件，无新增表或 migration。人工复核不会改变新任务的 A/B 归属；旧版已完成且没有模式证据的项单列，不伪造历史处理模式或精确完成时间。历史复用、模型新完成和最近一分钟完成量分别统计，跨月扩散不重复计数。
- 单图模型租约同时持有既有后台活动共享锁：helpers/requests 排空拒绝新领取，已领取项在完成回执事务成功后释放，失败保留至重试或原 3 分钟租约上界。模型／取图／图片处理使用同一处理期限，为回写预留时间。原维护的独占后台锁等待这些在途项；不新增生产维护入口。
- 先消费与当前业务图片哈希匹配的 R2 原图及 model-v1 衍生图；校验对象键、MIME、字节上限、签名和来源哈希，新衍生图另保存自身摘要。旧衍生图按现有来源元数据／固定键校验。失配、损坏、缺失回退原安全 JD 取图；新取图哈希变化拒绝旧候选推理。
- 新增“明确无标价”，价格与区间保持 null，要求至少 90% 置信度与图像依据。无法判断、尚未处理和失败分别展示。明确无价复用限同业务身份／同图／同 Prompt 与模型、原 AI 与人工复核均为明确无价且证据有效；不转换历史“无法判断”，不写 0。无价／无法判断入库不清除已有确认金额。
- 保留原列表、大图、筛选、人工编辑、选择与分页入库。页面显示 A/B 待处理、执行中、完成和异常，目标／实际并发、新完成量。恢复按“请求已接受／等待派发／正在处理／已暂停及原因”展示。

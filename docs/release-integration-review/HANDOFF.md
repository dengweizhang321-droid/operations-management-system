| 采用范围 | 源码/隔离验证/候选/实际采用分别填写；生产操作清单及授权边界 | 已合 main不等于已上线；默认本任务无生产采用许可 |

3. `tools/worker-local-release.mjs`、rotation、guard、Control/service/watchdog：A 的 `process-deadline.ps1`和C新增模块必须进入实际 runtime、保护入口、安装副本、恢复闭包；source-snapshot中存在不代表可运行安装齐备。
4. 生命周期参数：最终 StartWorker绑定 Worker/Django manifest、维护/排空 owner；C展示步骤类型/顺序不得因合并丢失。缺、错、重复参数在封存时拒绝，再在动作前现场复验。

# 市场分析模块 2.0

## 业务口径

- 市场分析仅代表“当前 TOP 榜单覆盖口径”，不得描述为完整行业市场。
- SKU 与 SPU 作为独立榜单维度保存、筛选和汇总，唯一键包含统计周期、类目、原始口径、榜单价格段、榜单维度和商品 ID。
- 经营模式规范化为 `POP`、`自营`、`未知`。自营占比默认按销售额计算：自营销售额 / 当前筛选范围总销售额。
- 页面采用双价格体系：
  - 主指标：市场定位价（主图），优先级为人工确认值 > 结构化源表价 > 系统计算成交均价 > AI 建议价 > 缺失。
  - 辅助指标：成交均价 = 销售额 / 成交件数。件数为 0 或缺失时返回空值。
- 行业价格 KPI 默认使用主图价格中位数，同时展示销售额加权主图价和成交均价。
- 价格带按照对应月份的市场定位价计算；无确认价格的商品进入“未确认价格”价格带。

## GMV 区间估算

- 京东商智榜单的 GMV、件数、访客、转化率等指标同时保留原文、区间上下界和中值；中值只作为无锚点时的排序与兜底值。
- 有效 GMV 在查询内存中按“类目 + 周期 + scope + 榜单价格段 + SKU/SPU 维度”分组计算，不覆盖导入事实：自有 SKU/SPU 的商智分天真实成交额是硬锚点，非锚点按排名双向收窄，并在前后锚点之间做对数（几何）插值，最后执行非锚点单调兜底。
- 有效 GMV 再与人工主图价、客单价区间、件数区间、访客和转化率区间联合约束，得到自洽的 GMV、件数、成交均价和转化率；真实锚点超出榜单粗区间时保留真实值，不用粗区间截断。
- “全部”或空价格段是基准段；同一商品同时出现在基准段和子段时只取基准段，子段只补基准榜未覆盖的商品，不跨价格段重复相加。
- SKU 数据库累计 GMV 按 `(SKU, 月)` 只选一个来源：整月榜选最优一行，分天榜按天选最优后求和，两者按覆盖天数择优；滚动窗口不参与累计，基准价格段优先。

## 数据结构

- `market_ranking_entries` 保留原始榜单事实，并新增：
  - `ranking_dimension`
  - `operation_mode`
  - `subcategory`
  - `price_band_filter`
  - `price_raw` / `gmv_raw` / `quantity_raw` / `visitors_raw` / `conversion_raw` 等原文列
  - `gmv_low_cents` / `gmv_high_cents`
  - `quantity_low` / `quantity_high`
  - `visitors_low` / `visitors_high`
  - `conversion_low_bps` / `conversion_high_bps`
  - `price_low_cents`
  - `price_high_cents`
  - `price_estimated`
- `market_price_snapshots` 按月保存市场定位价历史快照：
  - 源表价格、AI 主图识别价、AI 价格类型、AI 置信度、人工确认价、成交均价、价格区间、图片哈希、适用月份、确认人、确认时间、来源任务和 Prompt 版本。
  - 重新导入只更新源表和系统计算字段，不覆盖已有人工确认价。
  - SKU AI 标注提交会同步写入对应 SKU/SPU 的月度确认价。

## 页面结构

市场分析页分为四个连续工作区：

1. 商品榜单
2. 市场概括
3. 竞品对比
4. 系统和 AI 设置

全局筛选支持日期或月份、类目、榜单维度、经营模式、品牌、细分类目、价格带、商品标题或 SKU 搜索。所有 KPI、图表和榜单均由服务端按完整筛选结果计算。

## 管理入口

市场数据导入、SKU AI 标注、任务记录和 TOP SKU 主数据中心迁移至：

`市场分析 → 系统和 AI 设置`

该入口包含：

- TOP SKU 数据库概览
- 待确认主图价格（页面以元录入、数据库以分存储）
- 服务端分页、每页条数和上一页/下一页
- 市场数据导入
- AI 数据工作流与任务记录
- SKU AI 标注工作台

# 吉客云「货品」导出与导入操作手册

适用范围：吉客云“货品查询”全量导出，导入运营管理系统 `products`。每日自动化必须以[吉客云自动化状态机与下载后处理](./吉客云自动化状态机与下载后处理.md)为动作规范；不扫描最新文件、不打开“下载记录和系统任务”、不使用页面文件选择器。

## 1. 固定边界

- 货品是每日五类任务的第 1 项，使用同一个吉客云任务标签页和同一个 `RUN_ID`。
- 模式固定为“规格模式（SKU）”，没有快照日期，也没有刷刷仓过滤。
- 原始文件必须是本模块下载事件返回的 `D:\谷歌浏览器\货品导出*.xlsx` 绝对路径。
- 目标系统固定为 `http://localhost:3000`。

## 2. 状态驱动导出

1. 进入“货品查询”前记录 `navigationIntentAt`，确认模块身份。
2. 读取规格模式；仅当不是 SKU 时修改该字段，随后立即读回确认。
3. 等待本轮页面加载证据出现并恢复，页脚总行数或表格指纹间隔 500～1000 毫秒连续两次一致，将总行数保存为 `expectedSourceRows`。
4. 在同一受支持的浏览器调用中建立当前模块下载监听、持久化 `exportIntentAt`、在真实数据行右键并只点击一次“导出所有页（限 500000 行）”。
5. 等待下载事件返回绝对路径；确认最终扩展名为 `.xlsx`、无对应 `.crdownload`，文件大小和修改时间间隔至少 1 秒连续两次不变。
6. 本窗口出现同 SHA 副本时只交付最早完成的一个；出现不同 SHA 候选时立即 `BLOCKED`。

任何动作结果不确定时只读取状态，不重复切换模式、查询或导出。

## 3. 统一 runner

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\运营管理系统\tools\jackyun-download-runner.ps1" --module products --file "<下载事件绝对路径>" --run-id <RUN_ID> --export-start <exportIntentAt> --expected-source-rows <expectedSourceRows>
```

runner 在一次读取中完成轻量成功校验和正式导入：

- 文件名、目录、时间窗口、稳定状态和 SHA-256 绑定；
- 工作表及 `货品编号`、`货品名称`、`固定成本价`、`基础单位` 必需列校验；
- 真实源数据行数与 `expectedSourceRows` 精确一致，且处于正常的数千行量级；
- 按唯一货品编号计算导入行数；
- 使用 localhost 分片接口导入，并直接核对完成响应中的精确批次号、`completed`、行数及 `snapshotDate: null`。

成功路径不再额外生成完整单元格展开文件、预览图或人工 Excel 检查；只有结构或量级异常时才进入专项排障。

## 4. 成功与阻塞

成功审计位于 `outputs\jackyun-import-runs\<RUN_ID>\audit\products.json`，记录原始文件、行数、SHA、批次、警告和阶段耗时。只有 runner 返回 `completed` 才可进入分仓库存。

登录验证、页面无法证明本轮刷新、下载归属不明、行数不一致、必需列缺失或批次核验失败时，停止后续模块，不盲目重试。

```text
模块：products
原始文件：<绝对路径；字节；SHA-256>
页面/文件数据行：<expectedSourceRows>/<sourceRowCount>
导入批次：<batch id>
结果：新增 <n>；更新 <n>；排除 <n>；警告 <n>
快照日期：不适用
```

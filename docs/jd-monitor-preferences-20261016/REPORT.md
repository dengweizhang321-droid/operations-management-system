# 京东入仓监控：仓库设置与商品排序

日期：2026-10-16。基线：`2218679d`。范围：库存管理 → 京东入仓监控 → 库存监控。

## 实现

- 管理员按事业部配置来源仓库显示开关、显示名和顺序；弹窗支持拖动及上下按钮，空名称沿用来源名称。
- 仓库关闭后，从本页商品分仓、矩阵列、合计、健康计数及建议补货统计中排除；重新开启恢复。采集和独立缺货通知保留原策略，显示开关不静默停止通知。
- 同一城市内各来源仓库独立显示，仓库列、展开明细及筛选遵循同一配置，原始名称、仓库身份和日期依据保留。
- 商品行拖动保存全局顺序，上拖放到目标前、下拖放到目标后；键盘支持 Alt+↑/↓。后台在筛选和分页前应用顺序，保留未显示商品的相对顺序。
- 使用现有 Django settings 写入口、管理员权限、事业部 revision CAS、事务及审计。延迟成功回执在同一身份下更新对应事业部版本，切换筛选不会遗留旧 CAS；身份切换后不接纳旧响应。
- `0015_jd_monitor_preferences` 只增加两个 JSON 配置字段，无业务数据导入、清洗或回填；库存就绪检查包含新字段。

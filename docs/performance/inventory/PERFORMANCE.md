浏览器证据使用实际原组件/原CSS、180ms固定合成transport；它验证交互而不能替代业务PG性能。第一版六页候选首次反馈46–113ms、首内容326–634ms；旧总览首次4.86s包含Vite冷编译，不据此称业务提速。计划刷新曾439ms，memo后独立复测49.45ms/全页409.19ms；后续独立冷组件/账号测试仍有244ms反馈样本，样本保留，不能称全部动作稳定200ms。具体每动作值见UI证据。

背景：机器同时保留正常生产负载及其他隔离开发工作；部分样本与本任务构建/轻测试重叠，未独占CPU，也未量化其他进程因果。前后在同一个私有夹具上交替执行，不把跨环境数值直接比较。源码等价与性能证据分别成立。

未完成的目标：库存总览和备货计划冷范围HTTP全页约3.38s/2.78s，未达到1–2s参考目标；部分首次反馈超过200ms。共享Home、正式鉴权/Worker、真实业务数据分布、并发与P95尚未验，不宣称整个库存板块全部性能达标。其余页面全部有独立测量和回归，仍只确认所测范围。

# 商品经营完整覆盖清单

依据基线`app/shell/navigation-catalog.ts:34`的product views与实际`app/product-module-view.tsx`，本板块只有两个主Tab（overview/calculator），规格详情为Tab内drill页，没有独立URL route。网店商品表现、数据导入中的费率上传、运营事务的新品页面属于其他主板块，不纳入商品经营清单。

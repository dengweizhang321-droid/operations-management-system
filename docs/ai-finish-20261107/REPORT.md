## 组合核验

首次合并日报与恢复清单时，两项日报场景因新增原生分支绑定而在交接处失败，另有四个仅在 SQLite 下成立的压缩测试夹具。修复后用 PostgreSQL 复核。随后增加模型输入的跨代权限测试，修正其旧消息夹具的数据库序号，最终本次组合测试为 66 项通过，0 项跳过，未调用生产。

- 记录位于独立工作树的 `.runtime/ai-pg-90fa859d6dd2/tests.log`，SHA-256 为 `2398DB973DBE7D7E48425BABC4B8E3D73F7462C9F405D655CDAD495B52B740CF`。
- 浏览器侧分别验证了提炼界面、日报草稿请求的断线恢复、Worker 路径和跨轮正文显示；使用合成账号和供应商边界。定向 TypeScript 项目通过。
- 校验范围是本次功能与直接依赖。P2 原有较宽 TypeScript/后端依赖检查及 backup 测试的既有失败见[P2 报告](../ai-p2-20261107/REPORT.md)。未宣称整个仓库测试全绿。

# 日报停用草稿管理入口

入口为「AI → 定时任务 → 经营日报任务草稿」，沿用只有无范围管理员可访问的既有栏目。展开后读取当前账号可用模型和方法的版本，保存仅创建停用草稿，不授权模型、推送或真实定时。方法选择区分 Pi 内置技能与报告资源库方法。

首个场景固定为京东志高商用设备旗舰店。表单将 ERP 本店销售与计入库存的仓作为两项不同的数据依赖。计划时间是可编辑的草稿字段，未添加任何投递目标。用户可按页查看自有任务摘要，打开一条记录核对修订和启用缺项。创建使用稳定 clientRequestId，网络未知时重用原请求正文避免重复创建。一般统一任务的其他定义和历史明细按 P2 API 交付；这个界面只面向已选定的日报场景。

此界面依赖 P2 的任务定义和 draftOptions 入口，须与对应服务端及 0090 结构适配一起交付。[离线示意](配置与日报草稿.html)。

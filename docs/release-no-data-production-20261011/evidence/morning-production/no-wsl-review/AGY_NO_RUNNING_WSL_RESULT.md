**独立反例审查与最小边界意见**

**一、具体可触发反例与防御盲区**
1. **HCS 与宿主辅助进程撕裂反例**：仅断言 HCS 为 `[]` 且无 `vmmem/vmwp` 不足以确证 WSL 彻底离线。若 `wslhost.exe` 或 `wslservice.exe` 处于终结悬挂期，HCS 枚举可率先返回空数组，但残留宿主辅助进程仍可能持有 9p/网络重定向或文件锁。**最小边界**：Windows 普查不仅排查 `vmmem/vmwp`，必须将所有关联的 WSL 宿主辅助进程（如 `wslhost.exe`）一并纳入缺席断言，存在任何存活即拒。
2. **PID 47936 采 CWD 瞬态并发读取失败反例**：若 47936 正在退出，`OpenProcess(0x0410)` 虽可能成功，但后续读取 PEB/RTL 参数提取 CWD 时可能触发 `ReadProcessMemory` 失败。若异常未捕获或被误判为“无 CWD 引用”，将引发逃逸。**最小边界**：0x0410 成功句柄下 CWD 读取异常必须直接 Fail-Closed 判为 `unknown` 并中止；仅允许“两端皆为 87 且全 census 无该 PID”走消亡分支。
3. **HCS 原生 JSON 词法正则 BOM 误拒**：Windows 原生 API 格式化输出若带 UTF-8 BOM（`\uFEFF`），`^\s*\[\s*\]\s*$` 会因首字符非空白而产生伪阴性误拒。**最小边界**：在正则前必须完成严格 UTF-8 解码并剔除 BOM，再行纯 ASCII 空白与空括号断言。

**二、必要最小边界与合规底线**
1. **VM 缺席绝不等于 Guard 通过**：无运行中 WSL 仅豁免了客态 guest 内采样的必要性；2933/3468 全量 Windows 进程、服务与任务引用扫描必须完整执行且保持 0 引用，绝不放宽。
2. **审计与授权隔离**：调和仅追加证明“维护期停止 AI/WSL 后的物理无活 VM 事实”，旧 unknown 事实永不涂改；模型意见不替代 Root 独立封签与 OS UAC 主权确认。

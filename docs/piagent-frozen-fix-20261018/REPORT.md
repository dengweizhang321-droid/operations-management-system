## 修改

- 由可信 Pi 网关为实际提供的 `write/bash/edit` 指定每调用 256 KiB 预算；普通调用和中央业务工具的原有边界保持。模型声明的 schema 不授予更大预算，JSON 深度、键、列表及总传输限制继续执行。
- unknown 派发保存既有可信供应商异常的固定诊断字段；不保存供应商正文、代码参数、私有思考、密钥或 capability。重复冻结保留首个原因和诊断。
- 复用原 Pi 页面与错误区域，优先展示模型失败原因；事件读取服务端实际使用的 `code`。刷新后错误仍可见，unknown 操作继续禁止发送。

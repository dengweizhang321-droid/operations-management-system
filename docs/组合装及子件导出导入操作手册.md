# 吉客云「组合装及子件」导出与导入操作手册

适用范围：吉客云“组合装查询”双工作表导出，导入运营管理系统 `combos`。每日自动化必须以[吉客云自动化状态机与下载后处理](./吉客云自动化状态机与下载后处理.md)为动作规范。

## 1. 固定边界

- 组合装是每日五类任务的第 5 项，也是最后一项；同一 `RUN_ID` 的货品、分仓库存、库龄和销售必须都已完成。
- 使用同一个吉客云任务标签页；原始文件必须来自本模块下载事件。
- 文件保持吉客云双工作表原样，不拆分、不合并、不改列名。
- 组合装没有快照日期，也没有刷刷仓过滤。

| 工作表 | 用途 | 必需列 |
| --- | --- | --- |
| 第 1 张（通常为 `sheet`） | 母件映射 | `货品编号`、`货品名称` |
| 第 2 张（通常为 `sheet1`） | 母件—子件关系 | `母件编号`、`编号`、`名称`、`数量` |

## 2. 状态驱动导出

1. 进入“组合装查询”前记录 `navigationIntentAt`，确认模块身份。
2. 等待属于本轮导航的加载证据完成；页脚母件总数/表格指纹间隔 500～1000 毫秒连续两次一致，将总数保存为 `expectedSourceRows`。
3. 在同一受支持的浏览器调用中建立下载监听、持久化 `exportIntentAt`、右键真实数据行并只选择一次“导出组合装及子件 → 导出所有页”。
4. 等待并核对确认框同时包含“导出列中存在图片列”“最多只能导出2000条”“确定导出”，只点击一次“确定”；保存提示文本、按钮文案和 `confirmedAt`。未确认前不得开始计算下载超时，也不得重复点击导出。
5. 2000 条提示只说明图片列限制，不证明母子关系完整。统一确认导出后，仍用页面母件数与第一张表行数精确比对、两表母件覆盖和历史 95% 门禁拦截任何截断文件。
6. 仅接收下载事件返回的 `D:\谷歌浏览器\组合装及子件导出*.xlsx` 绝对路径；确认最终 `.xlsx`、无 `.crdownload`、文件间隔至少 1 秒稳定。不同 SHA 的多个候选立即 `BLOCKED`。

## 3. 统一 runner

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\运营管理系统\tools\jackyun-download-runner.ps1" --module combos --file "<下载事件绝对路径>" --handoff-file "<本轮 05-combos.json>" --run-id <RUN_ID> --export-start <exportIntentAt> --expected-source-rows <expectedSourceRows>
```

正式上传前 runner 一次性完成以下轻量门禁：

- 第一张母件表真实行数与页面 `expectedSourceRows` 精确一致；
- 两张表及所有必需列存在，母件编号/子件编号非空，数量为大于 0 的数值；
- 第一张表的每个唯一母件都出现在第二张关系表，第二张也不得出现第一张不存在的母件；
- 唯一“母件编号 + 子件编号”关系数不少于固定量级门槛；
- 从 `GET /api/imports/erp?source=combos` 读取最近成功批次作为权威基线；本次数量若低于其 95%，或没有可用成功基线，正式替换性导入立即停止并要求人工核验；
- 分片导入后直接核对完成响应中的精确批次号、`completed`、唯一关系行数和 `snapshotDate: null`。

以上覆盖检查可抓住“母件表完整、子件关系表被截断”的危险文件，避免后端替换导入删除未出现在本批次的历史关系。`--previous-combo-rows` 只允许离线 `--dry-run` 提供测试基线，正式任务不能用它覆盖系统历史。

## 4. 成功与阻塞

成功审计位于 `outputs\jackyun-import-runs\<RUN_ID>\audit\combos.json`，包括母件行数、唯一母件数、关系行数、历史基线、SHA、批次与警告。组合装是最后一步，只有 runner 返回 `completed` 才可将整轮任务标记为完成。

```text
模块：combos
原始文件：<绝对路径；字节；SHA-256>
母件：页面 <expectedSourceRows>；文件 <parentRows>；唯一 <uniqueParents>
关系：原始 <childRows>；唯一 <uniqueRelations>；最近成功基线 <previousRows>
导入批次：<batch id>
结果：新增 <n>；更新 <n>；警告 <n>
快照日期：不适用
```

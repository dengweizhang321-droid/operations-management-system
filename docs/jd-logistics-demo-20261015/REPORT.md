## 已核实的重要结论

1. 原簿商品对照 C/D 是 ERP 货品编号/名称，调拨 C 是人工状态。自动键排序与手工值按行存放可能错配；系统需按稳定的事业部商品键、调拨商品键维护人工结果。
2. 调拨行是“京东单据号＋事业部商品编号”，同单多商品分别核对；未来加入来源事业部隔离。调出/实收必须按相应事件与库存分量计算，不能把全部正负变动直接净额归零。
3. 负向变动不等于负库存。原簿结存没有发现负数；未含真实 ERP 单号、仓库和数量，不能证明 ERP 缺单或倒挂。人工确认与未来 ERP 真实回查应分列。
4. 同一事业部可见多家店铺，一事业部商品可关联多店。来源事实只保存一份，通过关系筛选，不按账号/店铺复制求和。
5. 流水与店铺商品入口、导出任务列表均已只读观察；未点导出。真实文件表头、稳定事件身份、完整导出范围、成功附件、下载请求和受控 Profile 登录仍待验证。

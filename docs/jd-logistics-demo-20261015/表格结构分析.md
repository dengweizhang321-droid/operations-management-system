## 商品对照表：C/D 为人工输入

`商品对照表!A1:E1` 的含义为事业部商品编号、商家商品标识、ERP 货品编号、ERP 货品名称、京东商品名称参考。

- A 列从辅助 H/J 的商品键及首次时间排序取唯一商品；B/E 依 A 键从流水回查。代表公式见 `A2/B2/E2`。
- C/D 是人工维护的 ERP 编码与名称；当前调拨表 `J2/K2` 按事业部商品编号查回 C/D，缺失时显示“待维护”。
- `Sheet1!A1:C1` 另有 POP SKU、吉客货品编号、吉客云名称，可用于人工核对候选，但现有核心调拨公式未读取它。不能把两份对照默认为同一权威来源，更不能用名称自动覆盖人工确认的映射。
- 当前映射在分析样本中无重复事业部商品键，已出现商品的 ERP 编码均有值。此结论不构成新商品自动匹配规则。

人工映射必须绑定稳定商品键，不能绑定第几行。现有 A/B/E 按最早业务时间动态排序，但 C/D 留在原单元格；补入更早历史事件、删除历史或改变同一最早时刻的顺序，可能让自动商品键移动，人工 ERP 值仍留在原行。`商品对照表!G2:G5` 中“新商品自动追加、已填内容不会错位”的说法成立需要历史和顺序前提，并非公式永久保证。

## 调拨单：C 列是人工确认，不是 ERP 接口证据

`调拨单!A1:O1` 依次为调拨单号、调拨状态、ERP 调拨状态、调出库房、调入库房、调出数量、调入数量、事业部商品编号、商家商品标识、ERP 货品编号、ERP 货品名称、商家单据编码、发起时间、最近业务时间、单据键。

当前聚合与状态机制如下：

| 输出 | 原公式证据 | 当前机制 |
| --- | --- | --- |
| 调拨业务键 | 辅助 A2；调拨单 O2 | 京东单据编码 L 清理后与事业部商品编号 H 用 `\|` 连接；仅纳入 N 含“调拨”的事件 |
| 调出数量 F | 调拨单 F2；辅助 D2 | “出库回传”且 U 小于零的变动取负后求和 |
| 实收数量 G | 调拨单 G2；辅助 F2 | “入库回传”且 U 大于零的变动求和 |
| 调出库房 D | 调拨单 D2 | 优先取负向出库回传的仓库；缺失时回退预占行 |
| 调入库房 E | 调拨单 E2 | 优先取正向出库回传的仓库；缺失时回退正向入库回传 |
| 发起/最近时间 M/N | 调拨单 M2/N2 | 同一业务键所有纳入事件的最小/最大业务时间 |
| 调拨状态 B | 调拨单 B2 | F=0 为已下发待出库；否则 G≥F 为已完成，G>0 为部分入库，其余为已出库在途 |
| ERP 调拨状态 C | 调拨单 C2:C2001 | 人工输入，不参与上面的京东状态计算；现有条件格式仅对空值或“未调拨”提示 |

同一单据有多个商品时，本表是“调拨单号＋事业部商品编号”的行，不是一张单据一行。未来不能只按单号存一个覆盖全单的人工状态，除非明确全单确认及分行确认的关系。

源事件中，预占将可销售分量转为内配出锁定；出库回传将内配出锁定转为在途；入库回传将同一目的仓的在途转为可销售。各阶段存在正负配对。`库存流水!N/O/S/U` 必须联合理解：负向变动并不等于负库存，在途和锁定分量也不等于可销售实物库存。

当前样本中按同一调拨键，没有发现多个调出仓、多个调入仓或多个商家单据编码混合。原公式只取首个匹配仓库和商家单据，未来出现此类冲突时应列为待核对，不能静默择一。

## 建单核对与“倒挂”的可证明范围

本簿没有 ERP 调拨单号、ERP 来源/目标仓代码、ERP 建单数量、审核状态、实际出入库量或 ERP 库存快照。C 列的“已调拨”只是人工回填。它能证明“有人填了此状态”，不能证明 ERP 建单成功、数量一致或库存已经过账。

本轮演示可据已有字段展示：京东待出库/在途/部分入库/完成状态、ERP 人工确认状态、缺商品映射、待 ERP 确认，以及每项结果对应的证据来源。对于京东已发生出库而 C 仍空或未调拨的行，可提示“京东已出库，ERP 待确认”；不得声称已核实 ERP 缺单或已发生库存倒挂。

要判断实际 ERP 账实不一致，仍需要 ERP 侧只读证据，至少核对同一货品、来源仓、目标仓、数量及业务时点，并保留 ERP 单号与核对状态。是否以“已建单”“已审核”或“已出入库”作为闭合条件，应由业务明确；三者不能互相替代。本轮不自动创建 ERP 调拨单。

库存负数应检查期末结存 V/Y，而不是仅检查带符号变动 U/X。本样本未发现 V/Y 负数，且所有读到的行均满足 T+U=V、W+X=Y。该结论仅覆盖用户提供的这份历史源文件，不代表当前京东或 ERP 实时库存。

| 时间标签含义易扩大 | M 是最早纳入事件时间，N 是最近纳入事件时间 | 不直接把 M 称为已核实 ERP 建单时间，也不把 N 称为 ERP 完成时间 |

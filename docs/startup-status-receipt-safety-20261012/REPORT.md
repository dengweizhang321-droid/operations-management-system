# Status receipt safety repair

This development branch changes two runtime source files. It does not modify the deployed f15 batch, any installed Django/Worker package, immutable watchdog version, task, task action, triggers, RunLevel, gates or process receipts.

The incident exposed two cooperating defects. The installed watchdog downgraded a configured read-only diagnostic driver to the legacy controller after a legitimate protected Worker entrypoint update from4c315… to717408…. The legacy Django resolver treated a CIM row with unreadable executable/command metadata like an absent process and removed its ownership receipt. Existing production logs preserve23 removals; their precise actor attribution is separate from this source repair.

The new Django Get-ProcessSnapshot uses terminating CIM errors and rejects duplicate rows. Incomplete image/command/birth metadata keeps the original bounded startup wait (default20 attempts,100ms spacing); if no complete instance is obtained after observing incomplete metadata, it throws instead of translating uncertainty into null/absence. Resolve-OwnedProcess supports explicit ReadOnly and enforces it for Status-suffix actions regardless of case. ReadOnly never deletes a receipt, including a genuinely absent process or a previous-boot mismatch. Seven calls in the actual core/finance/simple-domain Status helper graph explicitly pass ReadOnly, covering readiness checks invoked inside a lifecycle operation. Explicit lifecycle calls retain the original successful-CIM absence cleanup and separately verified previous-boot cleanup; this change does not add a native absence API or claim an OS-wide lock.

The new watchdog permits legacy compatibility only when none of the four driver files exists and the bundle does not declare any of them. Once configured, missing pieces, invalid binding or changed source hashes cause a failed diagnostic instead of invoking legacy. Hashes are never automatically refreshed. Existing probe-error behavior prevents recovery based on that failed observation.

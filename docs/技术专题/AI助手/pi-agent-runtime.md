# Pi Agent 一期运行说明

Pi Agent 位于“AI 助理 → Agent → Pi Agent”。原 Chat、Agent 工作流、DAG 与 pandas 沙箱继续使用各自路径。Pi 使用独立 Django 队列、操作账本、独立 Runner 和真实 `@earendil-works/pi-coding-agent@1.3.0` RPC 进程。

## 使用

1. 选择已启用的系统模型与运营分析技能，创建环境。技能来自已部署的可信资源包，并在每轮记录版本、内容摘要和资源清单。
2. 输入任务。可选择销售推广库存联合分析、库存积压与补货建议、Excel 报告；也可明确使用 `/skill:技能标识`。脚本在独立容器执行，不能获得业务写权限。
3. 查看执行状态、来源清单和文件，下载产物。上传文件是本环境内的不可信输入；HTML 等活动内容只作附件下载。
4. 下一轮沿用同一环境、工作文件和 Pi 历史。刷新或失联只恢复状态，不重发 prompt；结果未知时保留原操作栅栏。
5. 只保留一家店时，填写独立的“本轮店铺”平台和精确店名。服务端强制此范围，并切换新环境代际，隔离旧上下文和产物。单店环境只能使用有明确店铺归属的获准工具；不把仓库或 ERP 渠道假定为店铺。

来源分页完整不等于跨页原子快照。导出保留查询、字段、单位、来源域、版本、截止日、行数、完整性、文件 SHA 和缺口说明；无法证明的水位和映射不会补成完整事实。现有逐行明细的管理员限制保持。

## 首次安装与启动

源码合并和结构迁移不代表 Runner 已启用。默认没有 Pi 配置时不启动新执行器，不影响原 AI。

先在独立 rootless WSL 环境按 `containers/pi-agent/Dockerfile` 和锁文件构建并核验精确镜像 ID；本任务验证材料见 [Runner 证据](../../piagent-phase1-20261017/runner-validation.md)。镜像只能固定为 `sha256:<64位摘要>`，不使用浮动标签。构建所用 Node/Python 和 npm 包摘要均保存在该证据中。

由操作者在已采用对应源码、AI reader/writer 已停止时执行一次原生准备入口：

```powershell
& "D:\teruisi-runtime\django-sales\app\tools\django-ai.ps1" `
  -Action PreparePi -PiImage "sha256:<已核验的镜像ID>" -PiSkillVersion "1.0.0"
```

该命令复用现有 AI authority 和受管互斥，自动生成独立随机通道密钥；Windows 仅存当前用户 DPAPI 密文，Linux 私有密钥只经 stdin 写入。它安装固定源摘要的 Runner 和 user unit、写入绑定镜像及来源的 Pi 配置，**不启动服务，不启用独立登录自启动**。之后由原 AI Start/Stop 管理 Runner 和独立 Pi worker。无需在聊天中提供密钥或手抄 authority。

准备失败时保留 `config/pi-agent-prepare-intent.json` 及原现场，不删除记录后重做，也不自动换操作 ID。已有配置的升级不走首次准备命令。签名状态检查：

```powershell
& "D:\teruisi-runtime\django-sales\app\tools\django-ai.ps1" -Action PiCheck
```

本任务没有执行以上正式准备、生产迁移、服务启停或部署。应用发布仍由用户点击固定 `发布main.bat`；有限结构 recipe、安装器及隔离证明随源码交付。

## 恢复、资源与保留

- Pi 正常收尾必须有真实 `agent_settled` 和文件收集完成回执；`agent_end` 不独立代表完成。`disposition=handled` 无 run 另按命令回执完成。
- 用户停止和总任务期限会撤销新网关调用并发送正确 abort。已发送模型请求的结果未知不自动重放，不通过更换请求标识绕过。
- Runner 重启保留会话和工作文件。中断中的原操作冻结，精确停止所属旧容器，仍可读取状态并受控处理；已确定终态的会话可以恢复。
- 容器无网络、无宿主磁盘绑定、无生产凭据和 Docker socket。专属 Docker named volume 保存本会话 HOME、历史与工作文件。CPU、内存、PID、tmpfs 和单文件限制有硬边界；总工作区大小/文件数量采用软扫描，可能有扫描窗口超调，超限暂停环境并保留文件。
- 空闲停止保留持久工作区；取消不等于删除文件。权限收窄隔离旧环境、上下文及产物，不只清理 data 目录。当前不设置自动删除 TTL，持久字节保留随会话；物理删除须经受控维护，不能以自动清理抹掉未知操作与审计。测试环境清理只删除明确测试命名空间的容器及卷。
- 技能包仅在空闲安全点更新，重新发现后才使用；运行中的版本和资源摘要固定。资源错误、冲突和加载失败明确拒绝，不回退其他技能包。
- 技能选择控制本环境的活动技能和命令发现集；可信镜像中的其他预置只读技能源码仍可读取。勾选不是文件系统权限，也不能增加中央工具或数据授权。
- 库存试算脚本只输出建议；正式近 30 日、分仓、在途及补货口径优先消费原领域工具，不把任意窗口试算冒充正式库存指标。

网页终端、会话树、完整扩展 UI、公开联网研究、业务写入、真实 n8n 执行与多 Pi DAG 编排不在本期。

## 行为变化

| 用户问题 | 修复后的行为 |
| --- | --- |
| 模型无法删除 | 已结束执行和历史对话不再阻止删除。删除密钥及模型配置，保留原对话、消息、历史任务、执行回执；不重写历史模型身份。仍保护活动聊天、Agent 和待继续的工作流，保留权限和 CAS 校验。独立图片生成配置不在此需求内。 |
| 无法添加默认模型 | 模型卡片增加“设为默认”直接操作，使用原模型 ID/version，不要求重新输入密钥或所有参数。启用的文本与视觉模型均可作为默认对话模型，表单创建/编辑也支持；默认切换使旧默认版本递增，防止旧页面覆盖。 |
| 工具参数不设固定上限 | 已有主线/安装 Worker 的预算常量已为 JavaScript 可精确表示整数范围。保留其无固定产品上限的行为，并解除视觉模型工具参数输入框的禁用；按用户输入保存和执行，不自动替用户调整值。保留有效整数、工具自身权限/资源和取消约束。 |
| 删除后编辑状态异常 | 删除正在编辑的模型后清除该草稿；默认选择后同步该模型草稿版本和默认标志，不改其他字段。删除确认说明历史会保留。 |

独立 `set_default` 操作走现有 POST `/api/ai/models`、签名身份、管理员完整 scope、write receipt/审计及全 AI 域的 `mutation` 事务锁，不新增路由或凭据读取路径。原数据库条件唯一索引继续保护文本模型；文本和视觉的跨类型单一默认由所有配置写入均持有的原域锁和原事务清除逻辑保证，没有添加 migration 或放宽数据库/写入 authority。

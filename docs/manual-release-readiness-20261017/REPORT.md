## 变更

- 固定协调器在启动部署子进程前检查当前精确目标的原生准备记录。缺少时显示“发布包尚未就绪，本次未发布”、目标及打包日志目录，以退出码2结束，不启动子发布器，不现场构建，不获取rotation锁。
- 这只是前置提示。存在记录时核对版本、请求SHA、源码commit/tree，随后仍调用原 `--deploy-only`，完整原生锁、制品复验、前驱、迁移、维护与成功确认保持。
- 有部署STARTED但无SUCCESS优先按未知拒绝；目标选择后出现成功记录要求重新核线上，不能直接报成功。准备失败与中断的原记录保持，不自动重放。其他发布确实占锁时仍由原生入口拒绝，不吞锁错误或自动重试。
- `--check` 增加 `preparationStatus`，区分请求来源已冻结与原生包尚未完成。检查不部署。

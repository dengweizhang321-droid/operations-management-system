# W5-R1 活动报告复用请求绑定

2026-11-08。修复 [W5 独立反审](REVIEW-W5.md) 的 P1。原反审从 `ab8cb303` 复现两个缺陷，即同一复用请求号改选模型可以新建报告，及原报告终态后同号同体重试可以另建报告。

在原报告写事务中，活动命中时将本次请求号绑定到原报告。复用 `AiWriteReceipt` 的主体、权限摘要和正文摘要字段，以独立内部键和 `report_alias` 终态保存目标报告 ID。内部键不属于签名 HTTP 请求号语法，普通完成回执仍按七天清理。请求号重试先检查绑定，再核验目标报告和工作流的当前权限并读取状态。同号改换模型返回 409。同号同体在原报告取消或模型版本变化后仍返回原报告和原固定版本。用户以新的请求号明确创建，可在前一报告终态后使用当前模型版本创建。

变更只涉及 [报告入口](../../backend/ai_assistant/reports.py) 和 [报告专项测试](../../backend/ai_assistant/test_report_library.py)。复用现有写入互斥、表和权限，无结构迁移。修复前已复用且没有持久绑定的请求号缺乏可安全回填的历史依据。

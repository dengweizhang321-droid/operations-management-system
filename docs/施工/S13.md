# S13 · 蓝绿的可选采用与证据边界

**类型** 可选生产采用　**依赖** S12实际实现就绪、S05b　**优先序** 17

先读[看板](BOARD.md)与[执行约定](执行约定.md)。S12只写完设计不满足本单前置；须有明确实施范围、实际制品和已审共存/回退边界。不能修改看板状态来替代这些条件。

在对应授权下使用已采用入口完成切流/排空；不为演练故意破坏生产。原生完成回执负责发布完成，必要恢复能力检查在适当隔离环境进行。

若用户另行要求专门连续性测量，单列范围和证据分辨率：每5秒采样无失败仅表示采样点成功，不能证明最大中断0秒；一次只读成功不能证明可下单/写入安全。结合实际切流与请求时间线报告已观测事实和未知间隙。

没有专门测量授权时不追加业务验收，不宣称已证明绝对零中断。失败按已审适用回退/维护路径，不自动重放。取消本单不影响其他优化及主路线收尾。

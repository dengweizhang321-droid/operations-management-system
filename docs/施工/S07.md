# S07 · 维护优化采用与收益记录

**类型** 生产采用或不适用结案　**依赖** S06、S05b　**优先序** 10

先读[看板](BOARD.md)与[执行约定](执行约定.md)。有实际变更才准备/发布；可与已就绪且有收益的启动优化同批，不等可选项阻塞交付。

按实际目标、完整范围及授权使用原固定入口，复用有效PREPARED；原生成功后读取现有阶段记录，不额外做业务探活验收。

记录门外前置、进入维护、门内切换、退出维护/启动和必要收尾。维护状态时间与用户实际不可用证据分别列，不能把维护门退出直接等同于业务可用。比较总等待与中断两种收益，≤120秒仅为目标。

门外失败保留原异常且说明是否确无生产作用；门内失败走原适用恢复流程，不能自动重试。未达目标可关闭已成功交付的范围并明确差距；故障未闭合不能标通过。若S06无需改动，本单写“不适用，无生产动作”。

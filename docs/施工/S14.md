# S14 · 按证据优化首请求冷启动

**类型** 可选隔离代码　**依赖** S05c及实际可用的预热能力　**优先序** 14

先读[看板](BOARD.md)与[执行约定](执行约定.md)。不强制依赖S12/S13蓝绿。

仅有真实首请求与可比稳态数据、差距显著且预热覆盖根因时启用。没有数据或收益不成立则不做。首请求/稳态≤1.2可作原候选参考，不把单次噪声当稳定承诺。

优先复用已有受控只读预热，约束身份、数据范围、并发、时长及额外负载；无写入、发送或业务任务消费。隔离候选预热若需蓝绿支持，单独标明该实现的依赖，不把所有冷启动优化绑到蓝绿。

区分正确性ready与性能预热：必要依赖未就绪不能切换；仅性能预热失败可在原协议允许时记录降级继续，不能把真实故障叫预热失败放行。

交付根因、可用机制、净收益/额外负载、失败行为、最小必要检查及采用范围。不在本单自动执行生产业务请求或完整性能验收。

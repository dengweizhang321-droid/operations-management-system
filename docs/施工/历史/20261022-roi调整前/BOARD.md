## 全局纪律（每单都适用，各单文件里也会重申）

1. **只做本单范围内的事。** 遇需判断的情况停下报告，不自行决定。
2. **报告原始输出。** 不摘要、不改写证据、不删日志、不把失败说成成功。
3. **不读 `docs/规范/`。** 会导致上下文爆炸断线。本单明确要求时除外。
4. **不额外 `git fetch`。** 除非本单明确允许。
5. **不跳闸门。** 前一步没有明确产物，不许开始下一步。
6. **收敛/发布窗口内，机器上不许出现任何新的 shell 进程。** 该协议用**进程名**判定"有没有别的控制器"（`node|node_repl|powershell|pwsh|cmd|npm|npx|esbuild|rollup` 全部算），所以在写者+观察者跑的那 3–5 分钟里：不要开新的 PowerShell / CMD 窗口、不要跑任何脚本、不要让我（或任何 AI 助手）执行查询命令。开一个普通 PowerShell 窗口就足以让 `assertCrossCensus` 抛 `New possible controller after independent witness` 并让整轮收敛作废（S03 第一次失败就是这个原因）。
7. **`resolutions\` / `results\` / `dispatches\` 三个目录下的任何改名、移动、删除，即使"只是改名保留字节"，也必须先问。** 读路径按目录名定位证据（`<dispatchId>-evidence`），改名会让读者找不到、也可能让下一次写入走错分支。S03 曾未经确认把失败证据目录改名（`…-evidence` → `…-evidence-failed-crosscensus-20261022`）—— 结果无害，但流程上不允许。
8. **「搜不到」≠「不存在」。** 报告"某文件/某记录不存在"之前，必须**完整读过该文件**，不能只凭一次 grep 没命中就下结论。S03 曾因此误判 `S03.md` 里不存在「阶段 A 已完成」记录（实际在第 22 行）。同一错误若发生在"回执是否存在""终态是否完整"上，会直接导致错误发布。
9. **adopt 之后，准备/发布的入口只能是 `S\发布main.bat`（或 `S\准备main.bat`）。** 任何 checkout / worktree 里的 `发布main.bat` 副本都会被控制世代门禁拒绝（`Control generation changed; old consumer refused`）。S04 曾先在 `merge-20261022` 里执行而被拒，改用 `S\发布main.bat` 才继续。
10. **准备/发布是长任务（构建前端约 24 分钟），期间绝不关闭任何控制台窗口、不按 Ctrl+C、不让承载会话结束。** 一旦被杀，计划任务会留下 `LastTaskResult=3221225786`（`0xC000013A` = `STATUS_CONTROL_C_EXIT`），票据终态变 `unknown` 且**没有 `FAILED.json`**，进而按队列规则**锁死后续所有准备**（`Prior dispatch lacks a complete terminal result`）—— 2026-10-21 的 e786 与 2026-10-22 的 `a3d53227` 都是这样。准备日志末尾那行「请保持窗口打开」不是客套话。
11. **收敛（`cleaned-preparation-writer/observer`）的"跨普查一致"是按进程名判定，不看命令行。** `preparation-resolution.mjs` 的 `possible(name)` 匹配 `node|node_repl|powershell|pwsh|cmd|npm|npx|esbuild|rollup`；观察者取一次普查、写者随后再取一次，凡**两次之间新出现**的上述名字进程都会触发 `New possible controller after independent witness` 并让整轮作废。**因此：(a) 每一条 AI 工具调用都会新建一个 `powershell.exe`（`Temp\ps-script-*.ps1`），用户手开 PowerShell/CMD 同理 —— 窗口期内一条命令都不能跑，包括"只读查询"；(b) 常驻 `TERUISI Operations Watchdog`（`pwsh.exe … operations-system-watchdog.ps1`）实测每 1–2 分钟触发一次、单次存活 7–8 秒，会直接撞进窗口；(c) n8n「新品销售周报」每约 5 分钟派生 `cmd.exe`+`powershell.exe`、存活约 64 秒，同样撞进窗口。** 开收敛窗口前必须先静默这三类来源（临时停用相关计划任务 / 暂停该 n8n 工作流），窗口内**任何人（含 AI）不得执行任何命令**，窗口结束立即恢复。

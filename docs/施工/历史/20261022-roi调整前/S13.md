# S13 · 发布⑥（D1 零中断）

**类型** 生产发布　**依赖** S12 通过　**独占生产** 是　**预计** 40–60 分钟

> 规程沿用 **S04** 三步，但验证方式改为「持续探活」。这是第一次真正做到零中断，验收最严。

---

## 差异 1 · 前置探活

发布**开始前**就启动外部探活，每 5 秒采样一次，覆盖整个发布窗口：

```
记录：时间戳 / HTTP 状态 / 响应时间 / 是否命中维护页
```

发布结束后继续采样 2 分钟，确认恢复稳定。

---

## 差异 2 · 核心验收

| # | 指标 | 目标 |
|---|---|---|
| 1 | 站点可访问性 | **全过程 100% 可访问**，无采样点失败 |
| 2 | 维护页出现次数 | **0**（异常兜底除外） |
| 3 | 最大不可用区间 | **0 秒** |
| 4 | 最长响应时间 | 报告实测值 |
| 5 | 可下单验证 | 至少 1 次真实只读业务请求成功 |

---

## 差异 3 · 回退演练

在**不影响生产**的前提下验证一次回退路径可用性。

若无法安全演练 → **只报告静态核验结果**，不要硬演练，不要为了演练制造风险。

---

## 差异 4 · 特有风险

本单是第一次真正零中断。

- 任何一点不确定 → **回退到维护门方案**
- **不得用「看起来没断」来宣布成功**，要靠采样数据说话

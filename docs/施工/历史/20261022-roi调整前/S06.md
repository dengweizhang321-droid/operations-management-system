## 必须遵守的不变式

1. **门内动作集合只减不增。** 任何被前移的动作必须证明它不依赖「业务已停」。
2. **业务关闭语义不变。** 用户可见的「系统暂停」时长不得因前移而变长。
3. **证据可以前移，证据的最终提交仍必须在门内完成。**
4. **失败关闭。** 任何一步前置校验失败，必须在进入维护**之前**终止，不得进入维护再回滚。

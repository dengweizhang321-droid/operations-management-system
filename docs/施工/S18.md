# S18 · ROI 结算与必要归档

**类型** 文档/限定归档　**依赖** S17、S07　**优先序** 11

先读[看板](BOARD.md)与[执行约定](执行约定.md)。可选项未实施不阻塞收尾；后来实施再追加，不重做已完成发布。

## 汇总

按实际批次列目标、控制/应用采用、准备等待、用户上线后等待、就绪后执行、维护/可用性证据、失败/人工介入、净收益及样本限制。不是固定八次发布表，不把模板目标填成实测。

分列已完成源码、已合并、制品就绪、实际采用、无需实施、可选未做、仍阻塞和未达目标。准备优化与维护前移不能重复记省时；已存在能力不算新增成果。

## 归档边界

历史记录与原回执保留，纠错用追加结论；恢复后现场事实仍需精确身份、原操作/版本/消费链绑定，不能写“一律采信现场、不再比对旧字节”的泛化规则。

复用已有有效检查，不重开S01–S17全套复审。工作树按项目规范逐一核已合并、干净、无占用及证据保全；不是只留生产树其余全删。计划任务清理需精确归属与对应授权，不能以“曾未运行”单独认定可删。

更新本轮报告、导航和非敏感共享记忆。用户只要求文档时不执行生产或无关清理；有未完成项如实报告即可，不为追求全绿扩充工程。

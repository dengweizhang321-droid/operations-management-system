# S04 · 发布①（A1 gate 修复生效）

**类型** 生产发布　**依赖** S03 通过　**独占生产** **是**　**预计** 40–50 分钟

> 本单是后面所有「发布N」的**规程基准单**。S05 起每一单都沿用这里的三步规程，只更换目标与验收项。
> 全程不得并发任何其他发布、准备、收敛、启停命令。

---

## 前置判定（只读，30 秒）

进入本单前先确认：**队列不再 blocked**。

至少要看到一张近期的票，其 `status` 是 `prepared` 或 `non-production`。

否则 → **停止，回 S03**。

---

## 工作目录

在一个与最新 `origin/main` 完全一致的干净 worktree 中执行，入口是该目录下的 `发布main.bat`。

```
配置 = D:\codex-isolated\main-manual-release-20261016\main-publisher-config.json
```

---

## 步骤 1 · 准备（不部署）

```powershell
cd <worktree>
.\发布main.bat --prepare-only --no-pause
```

- 预期 **13–18 分钟**。设置 ≥30 分钟超时
- **禁止**在 5 分钟判定「卡住」
- **禁止**因超时或中断重跑
- **禁止**并行开第二个准备
- 必须产出 `PREPARED.json`，记录路径与 sha256

**若出现：**

```
准备请求需要处理，原记录保留：<id> / blocked
```

→ 队列仍未解锁，**停止并回 S03**。

---

## 步骤 2 · 发布

```powershell
.\发布main.bat
```

只消费上一步的已准备包。

若报尚未准备 → **停止**，不许现场重新打包。

---

## 步骤 3 · 验证（三条，缺一不可）

1. **「退出维护」阶段的 stdout 与 stderr 全文**，确认无 `worker_gate_failed`
2. 状态工具显示成功，且**不是人工恢复标注**
3. 站点可访问、版本指向本次候选

## 失败分类（只分类，不修复）

| 类 | 判据 | 动作 |
|---|---|---|
| a | 与 wrangler 版本事实 / 依赖清单相关 | 新检查有问题，**立刻停** |
| b | `worker_gate_failed` 但与版本无关 | 别的门禁，记录并停 |
| c | 超时 | 记录阶段、超时秒数、卡在哪个子进程 |
| d | 其它 | 原样记录 |

## 变更

- 固定可信扩展提供模型可调用的问卷与计划保存，经现有RPC交互子协议映射网页表单；保留取消、一次性回答与原operation/generation绑定，不执行TUI自定义组件。
- 新根树状态与不可变计划版本支持执行/计划切换，用户开始执行绑定计划、模式、树及范围版本。Django和Runner共同限制本地执行及业务准入，计划模式使用固定分析helper和独立scratch。
- 独立Pi会话、容器、操作及能力支持嵌套派工、消息、续聊、等待、取消、关闭与不可变文件交接。默认三个并发子运行，可按部署资源配置；原任务意图与唯一业务委派执行者保持，不复制授权或父凭据。
- 复用原AI对话壳和subnav，提供问卷、计划、代理树、目标选择、真实队列状态、可视历史分叉、实际思考档及Skills诊断。父轮结束与整树结束分开显示。
- 原生Skills语义用于新内置1.3.0包，旧1.0.0/1.1.0/1.2.0包保留原字节。仅审核内置根，未增加用户技能导入或任意扩展加载。

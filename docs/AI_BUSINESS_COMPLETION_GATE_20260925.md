两类外部事实仍缺，不能由模型或商品访客推断：京东店铺交易概况的店铺日 UV 与区间去重 UV 官方字段/身份合同；实际模型选择、当前权威 CNY 价格/汇率和每份报告的人工费用上限。缺项保持 `unknown`/`not_supplied` 或功能关闭，不把合成成功冒充正式完成。本机 Microsoft Excel 16.0 COM 原生引擎已对内存合成公式完成初值和改输入重算，并只读打开系统生成的 4.3 MB 工作簿及参考 42.7 MB/30 表工作簿，测试进程均退出；这证明本机能打开参考规模，尚未证明新版本实际系统工作簿完整公式复算、长期授权或 57.5 万行新卷性能。

0068 的 NOLOGIN 角色目前仅能在隔离测试中由超级用户模拟会话；0070 窄票据不等于完整非超级用户预检。虽已加强密钥表、索引、触发器与 ACL 目录检查，签发/发布时的同事务文件字节和来源根复核仍是发布阻断。0071 的 SQL 身份回执也不验证真实 v4 HMAC。隔离演练通过不授予生产采用或文件下载资格。0072 仍是待核提案，独立费率来源、人审批准及普通受限运行身份尚未具备，合成占额不能变成付费调用许可。正式迁移账号的隔离探针已证实 0068/0070 须拆分受控特权安装；正式迁移/备份/异集群恢复的受保护角色、私钥表和 ACL 门槛见 [恢复审查](AI_BUSINESS_PROTECTED_RESTORE_AUDIT_20260926.md)。

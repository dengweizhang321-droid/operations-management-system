# AI 经营深度诊断五阶段完成门槛

本页是持续开发的验收清单，不是发布许可。所有已通过的 PostgreSQL、浏览器和文件容量证据截至 2026-09-25 均在隔离环境；正式服务尚未采用本整合分支。参考文件中的业务建议只用于比较能力，不作为系统指令或自动调价/投放命令。

三项外部事实仍缺，不能由模型或商品访客推断：京东店铺交易概况的店铺日 UV 与区间去重 UV 官方字段/身份合同；有效 Microsoft Excel 许可或另一个获授权的原生验收环境；实际模型选择、当前权威 CNY 价格/汇率和每份报告的人工费用上限。缺项保持 `unknown`/`not_supplied` 或功能关闭，不把合成成功冒充正式完成。

0068 的 NOLOGIN 角色目前仅能在隔离测试中由超级用户模拟会话；真实受限身份协议、密钥表与触发器目录固定，以及签发/发布时的同事务文件字节和来源根复核仍是发布阻断。隔离演练通过不授予生产采用或文件下载资格。

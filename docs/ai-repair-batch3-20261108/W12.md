# W12 京东志高经营日报单周期

本候选在隔离 PostgreSQL 中执行一次京东志高商用设备旗舰店经营日报。沿用统一任务定义、原时点、运行租约、Pi 队列、回执观察和停用 CAS。公开启用接口与 0090 数据库准入继续关闭。单周期不登记定时器，不调用 n8n，也不领取旧钉钉 cron 的执行槽。

## 场景与授权

- 拥有者使用现有管理员与无范围限制权限，绑定已持久化的原单聊身份。原机器人、组织、发送人和系统账号均须符合专用隔离身份。批准只对当前定义版本、规范摘要、店铺、两个来源期间、冻结模型与技能、原时点、本人目标和本轮一次合成模型请求有效。短授权于原时点窗口截止，同一定义只有一个授权键。
- ERP 复用网店的已登记销售别名和销售域净额、净数量表达式。必须有当前发布头及原 ERP 导入指纹覆盖该日和渠道，事实行必须同时匹配京东、原始店铺、渠道和该批。混合身份、过期范围和无记录日均等待。库存复用库存域最新已发布分仓快照、库存 revision 和有效仓库映射。要求精确日期、发布指纹与行数，库存范围独立于店铺，取计入仓的可用量并排除刷刷仓。
- 读取前后核对销售/ERP revision、库存 revision 和仓库映射摘要。缺口留在原时点并记录分诊，满足后在原租约内将批次、revision、值和摘要绑定到唯一 Pi 操作。技能沿现有目录选择，实际冻结的版本和摘要须与任务相等才可在同一事务附接。
- Pi 的原模型请求和最终正文须匹配，才生成可确认的投递预览。拥有者确认包含原操作、请求、来源、正文和目标的摘要后，钉钉写出边界才可预留原投递身份。平台接受结算为 `sent`，明确拒绝或确认未写出结算为 `failed`，其余未获回执结算为 `unknown`。接受只证明合成平台受理。停用先提交则阻止新模型请求或新收件人请求；收件人请求先预留则允许观察原回执。无论结果如何，均不换 ID 或目标补发。

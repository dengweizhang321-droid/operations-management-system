## 实现与支持边界

分类、数据库策略、运行组件切换分别判断。首轮机器支持同结构 CSS 展示值及满足被动字面量边界的静态 TSX；以前驱到最终候选完整差异、请求／副作用、部署启动输入、迁移／写入／导入／存储／依赖、精确源码和制品证据共同授予资格。HTTP GET、前端目录、Django 摘要或人工布尔值不授资格。支持范围外的只读后端、权限变化、结构兼容写逻辑等保留严格流程并指出缺口。

`not-required` 在封存时数据库 operationIds 即为空，不依赖26小时恢复点、7天演练或日调度资格，也不是执行中跳过。Worker-only 保留原排空、切换、启动和解除；后端仍走必要应用准备及服务切换。自然业务变化无需生产全库前后相等。

新 v4 `targeted-first-adoption` 严格重算十工具完整迁移闭包及前后 Django 完整库存。19操作包括原 Backup、新 Worker apply、引用守卫、原 Deploy/HardenAcl、新 installed 无参数只读恢复消费 planner、同一 Backup 收据的原隔离 Restore、原启动及必要验收和收尾。两个 DB 操作各1800000ms声明预算，原30分钟硬上限不改。失败保留门、owner、WAL，不自动重放或数据库回退。

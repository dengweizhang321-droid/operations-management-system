# 规范目录

这里保存开发与自动化协作需要的稳定规则。根 [AGENTS.md](../../AGENTS.md) 是简短入口，[README.md](../../README.md) 是使用说明。正文只在所属专题维护，其他入口通过链接引用。

## 按任务阅读

| 专题 | 适用范围 |
| --- | --- |
| [开发与交付](开发与交付.md) | 所有任务必读；隔离开发、Git、清理、复用代码、文档和记忆维护 |
| [系统架构](系统架构.md) | 模块及领域所有权、前后端职责、跨域接口与运行边界 |

## 内容归属

- 开发约定与索引放根 `AGENTS.md`，不得再追加每日开发内容。
- 当前功能和操作入口放根 `README.md`；领域规则或实现细则链接至本目录及已有专题手册。
- 稳定规则发生变化时修改对应专题，并检查相关入口；不要把同一段正文复制回两份根文档。
- 每日进展、一次执行、发布和验收证据放 `docs/<任务目录>/`；候选与实际采用必须分别说明。历史归档不作为未来日志入口。
- 反引号代码路径相对仓库根目录，Markdown 链接相对所在文档；移动文档时同步检查相对链接与章节引用。

本次拆分沿用既有工程边界，历史版本和运行数据从根入口移出；它不产生生产部署、数据修改或后续维护授权。

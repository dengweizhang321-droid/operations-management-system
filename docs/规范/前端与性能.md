# API、前端与性能要求

路径约定：反引号中的代码、配置和工具路径均相对仓库根目录；Markdown 链接相对本文件。

- 商品经营总览的分区必须同时绑定完整查询scope和来源snapshot；snapshot只证明来源版本，不能替代日期/筛选身份。initial-page的完整full退化可内联全量指标，避免公共结果超容量/不可缓存时两个区域重复扫描。复用完整基行后仍从授权完整集合筛选、排序和重算指标；浏览器测量须把旧内容可用与本次新内容提交/绘制分开，不将一次样本称稳定P95。具体协议与限制见 `docs/PRODUCT_OVERVIEW_SPEED_PILOT_20261005.md`。

- API 响应默认 `no-store`，除非实现了显式版本指纹、失效策略和并发复用的持久缓存。缓存不能绕过身份、scope 或数据新鲜度。
- 列表和搜索在服务端筛选、分页并设置硬上限，同时返回 `total/returned/truncated` 等必要元数据；不得把数万行完整数据发到浏览器再筛选。
- 用户连续切换筛选时取消旧请求，并用 request key/generation 等门禁阻止迟到响应覆盖新状态。不能只靠前端防抖掩盖慢查询。
- 市场 SKU 图片 AI 标注的模型并发数按“三级类目 + 执行器”持久化，范围为 1–50；云端默认 10、建议 10–20，本地 Ollama 默认且建议 1。Cloudflare `scheduled()` 只允许唤醒 Django 持有的市场队列，页面只允许启动/暂停和轮询进度，不得把调度依赖浏览器存活。运行状态、自适应并发、冷却截止时间和唯一协调租约必须持久化到 PostgreSQL 市场域；重叠定时触发、页面启动与暂停交错时仍由协调租约和单图租约双重防重。新任务设置与当前任务控制必须分区展示，当前任务运行中保存并发后要更新服务端租约上限，后台在下一批即时应用。每个模型 HTTP 请求只处理一张图片，服务端必须使用同一持久化配置和原子条件限制任务的有效推理租约，不能只靠调度器并发数防越界；同一任务中“类目 + scope + SKU + 榜单维度 + 图片哈希”相同的跨月记录只能领取一个推理单元，成功结果要批量扩散，扩散失败必须可恢复且不得重复调用模型。视觉模型调用、启动页面请求与推理租约依次限定为最多 90 秒、110 秒和 3 分钟。单次模型超时或网络异常先把当前运行并发降到约 75%（配置不少于 4 时首次不低于 2），从 5 秒短冷却开始，重复异常再阶梯减半且普通异常冷却最多 30 秒；普通异常的冷却只作用于触发异常的通道，其他通道继续运行，同一冷却窗口内并发返回的同类失败只计为一次退避事件。供应商限流按当前并发减半并使用 60 秒至 5 分钟全局有界退避或供应商 `Retry-After`；租约占满只让对应通道短等，不得暂停其他通道。连接每连续成功 3 张增加一路，直至恢复该类目的配置值；运行并发已为 1 后若没有成功图片又累计 3 个独立失败窗口，后台必须自动暂停，显示服务端返回的有界脱敏错误码与原因并要求人工检查后续跑，不能无限重试。续跑必须复用兼容且仍有可重试推理单元的原任务；单任务最多 10,000 条，`review_ready`、`committing` 或失败封顶的旧批次不得占用可运行工作键或拦截下一批，唤醒无可重试单元的任务必须失败关闭并提示创建下一批。不得因客户端超时重复创建仍在运行的任务或覆盖已完成结果。模型输入图可使用 Cloudflare Images 将最长边缩至 1600 像素并编码为质量 88 的 WebP，但只在衍生图小于原图时采用；转换失败或结果无效必须回退原图，衍生图可按原图内容哈希持久化复用，不得改变业务图片哈希、正式价格继承身份或人工复核所见原图。豆包 Seed 系列的该类严格 JSON 分类/抽取请求必须关闭额外思考，完整分类输出上限为 600 tokens，仅价格识别上限为 320 tokens。单图取图、图片处理、模型调用、总耗时和输入字节数要持久化，页面至少展示最近 100 张的分阶段平均值。
- 市场 AI 待标注总量必须按类目、scope、SKU/SPU 维度和商品编码去重，并互斥拆分为同图直接复用、新图仅识别价格、完整分类与价格、暂不可自动识别；同一身份跨月份命中多种路径时按算力需求“完整识别 > 仅价格识别 > 同图复用”归类，四类合计必须等于待标注总量。无图、非 SKU、有效 Prompt 缺失或失败封顶归入阻塞，不得误报为模型调用量。
- 新查询要避免逐行 N+1、无界 `IN`、重复全表迁移和无变化 UPDATE。对高频聚合优先使用有版本失效的派生表或响应缓存，并用真实规模数据比较结果等价性和时延。
- 全局搜索新增领域时同步更新 `lib/search/` 覆盖、权限、结果边界和文档；数据应可被 AI 查询时还要按[安全与AI工具](安全与AI工具.md)接入中央注册表。

- 市场榜单分页维护必须保持数据库内去重、正式价格与投影后排序的口径，只为当前页查询关联销售；不得通过提高原始记录上限或返回截断统计冒充完整结果。首次读取失败仍须保留日期、筛选及子菜单，选项独立读取；迟到结果不得覆盖新范围。行业汇报的有界计算与榜单分页分别验收，细节见 `docs/MARKET_QUERY_PAGINATION.md`。

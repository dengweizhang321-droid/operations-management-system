## 三个口径与完整交付新证据

**T1** 是精确批准到完整交付（必要验收、报告/材料、Git远端验证和记忆等本批要求）的墙钟。只有批准和完整终点都绑定本批才实测。completed 是批次状态，不能默认作为完整终点；阶段并行时取关键路径/区间并集，不把 duration 总和当T1。

**T2** 分别记录维护门、精确进程停稳、HTTP/业务就绪。持久维护且 drainedStopped 的中间区间可证明发布路径阻断/应用停止，但不等于所有业务持续不可用秒数。HTTP失败是有限采样；失败段只表示相邻失败样本，段内可短暂恢复，成功样本也不能证明段间持续健康。无凭据401是预期权限拒绝，不能证明认证业务成功。

**T3** 分类为失败执行、unknown→独立补证、恢复执行、验证采集错误及等待/收尾。补证跨度包含诊断、开发、授权续接和未打点工作，不能全称人工等待、机器空闲或EOF等待。T3通常包含在T1且可能重叠T2，三者不相加。必要的正常隔离Restore与故障恢复分开。

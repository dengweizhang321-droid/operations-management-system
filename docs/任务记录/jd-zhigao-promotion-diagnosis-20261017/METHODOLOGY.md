# 京东志高商用设备旗舰店推广诊断方法

## 任务范围

- 分析店铺：推广标准店铺 `京东 / 志高商用设备旗舰店`。
- 销售受控别名：`京东 / 志高商用设备旗舰店（亿用） / 京东-志高商用设备旗舰店（亿用）`。
- 近 30 天：`2026-09-17 <= 日期 < 2026-10-17`。
- 前 30 天：`2026-08-18 <= 日期 < 2026-09-17`。
- 本自然月截至昨天：`2026-10-01 <= 日期 < 2026-10-17`。
- 上月同期：`2026-09-01 <= 日期 < 2026-09-17`。
- 业务时区：`Asia/Shanghai`。

## 数据来源与保护

运营数据 MCP 在本次会话不可用。用户已明确授权读取数据库，因此本任务使用本机 PostgreSQL 的既有最小只读角色作为替代来源：

- 推广和商品主数据：`teruisi_netshop_reader`。
- 销售和成本：`teruisi_bi_reader`。
- 两个连接都在 `REPEATABLE READ, READ ONLY` 事务中运行，并核验 `transaction_read_only=on`、非超级用户、无建库和建角色权限。
- 凭据仅由运行包装脚本在当前 Windows 用户下解密到子进程环境，脚本和产物不保存凭据。
- 未执行导入、修改、删除、发布、外部发送或推广后台调整。

## 数据完整性

1. 以 `netshop_promotion_shop_daily` 取得逐日店铺指标。
2. 对同日 `netshop_rows` 原始推广行核验五项数值存在性缓存：花费、归因成交、展现、点击、订单行。
3. 原始行数、逐日聚合行数、聚合状态行数及五项指标逐日一致才视为对账成功。
4. 近 30 天覆盖 30/30 天，未出现缺日或未对账日期；推广批次警告数为 0。
5. 推广、销售均覆盖至 2026-10-16；商品主数据快照日为 2026-10-17。
6. 当前批次只证明业务日后的单次快照，未观察到同一业务日按京准通归因窗口回溯重导的证据。因此归因成熟度标为“未验证”，动作均为平台回查后的条件候选。

## 指标口径

- ROAS = 京准通平台归因总订单金额 / 推广花费。
- 点击率 = 点击 / 展现。
- CPC = 推广花费 / 点击。
- 点击转化率 = 归因订单行 / 点击。
- 净销售额 = ERP 分摊后金额合计，退款以负值参与。
- 大毛利 = 净销售额 - 货品成本，不扣费用分摊。
- 店铺广告后大毛利 = 店铺大毛利 - 同店推广花费。跟单 SKU 簇花费不是独立 SKU 预算，因此不计算 SKU 广告后大毛利。
- 推广费率 = 推广花费 / 净销售额。
- SKU 盈亏平衡 ROAS = 1 / SKU 大毛利率，仅在京东 SKU 通过商品主数据中的“商家SKU”唯一映射到一个 ERP 货品，且该商家 SKU 未被多个京东 SKU 共用时计算。

平台归因窗口未知。ROAS 只表示平台归因金额和花费的比例，不能解释广告增量、自然成交替代或最终净利润。

## SKU 映射

商品主数据中的京东 `SKUID` 与 ERP `商家SKU` 用于连接推广和销售成本：

- `matched`：一个京东 SKU 唯一对应一个商家 SKU，且该商家 SKU 未被其他京东 SKU 共用。允许计算 SKU 销售和利润。
- `shared_erp_code`：多个京东 SKU 共用同一商家 SKU。保留推广判断，不把整笔 ERP 利润重复分给每个京东 SKU。
- `ambiguous`：一个京东 SKU 对应多个商家 SKU。利润保持未知。
- `unmapped`：没有可用商家 SKU。利润保持未知。

## 投放身份与控费规则

原始京准通表同时包含跟单 SKU、智能投放推广 SKU、触发 SKU、计划、关键词和搜索词。系统商品聚合使用跟单 SKU 归因视角；该行花费不等于这个跟单 SKU 的独立投放预算。

- 跟单 SKU 只用于发现异常归因终点。
- 每个异常终点拆分“同号推广 SKU 花费”“`-1`/空池归集”和“其他推广 SKU 归集”。
- 实际可控对象使用计划 ID；关键词和搜索词用于计划内定位。
- `-1` 代表计划池，不得按跟单 SKU 直接停投或减预算。

跟单 SKU 高花费门槛取以下三者最大值：

1. 100 元；
2. 店铺近 30 天推广花费的 1%；
3. 近 30 天花费不少于 100 元的活跃 SKU 花费 P75。

达到门槛后，出现下列证据之一才进入异常归因终点：

- 点击不少于 20 次且归因订单行为 0；
- ROAS 低于店铺近 30 天 ROAS 的 65%；
- 唯一映射 SKU 的 ROAS 低于其毛利盈亏平衡线的 115%；
- 花费较前 30 天增加至少 30%，但归因成交未增长；
- 本月截至昨日仍低于店铺同期水平。

计划审计门槛取 200 元与店铺花费 1% 的较大值。达到门槛且出现低 ROAS、花费增而成交不增或本月继续走弱的计划进入审计清单。只有在京准通后台确认成熟归因、实时预算、出价和投放状态后，才允许使用 15%—50% 的条件性下调情景。

## 低投放规则

低投放候选必须满足：商品上架、库存没有明确为 0、商家 SKU 唯一映射、大毛利为正。候选来自两类：

- 已有少量投放：近 30 天花费低于有意义活跃 SKU 中位数、至少 3 个归因订单行、ROAS 同时高于店铺水平的 125% 和毛利安全线的 120%。
- 零明确关联花费：同一 SKU 在跟单 SKU、智能投放推广 SKU、触发 SKU 三种明确身份中均未观察到花费，且近 30 天平台成交或映射大毛利达到同店 P75。

商品主数据为“分区库存”时，候选可进入清单，但实际增投前必须在京东后台核对可售库存。

## 预算情景

- 计划清单计算的是近 30 天条件性收回情景，不是当前已确认可释放预算。
- 先按 `30 天情景 × 7 / 30` 折算 7 天等速释放情景，避免把 30 天历史金额直接用于 7 天试投。
- 7 天等速释放情景最多 50% 分配给试投候选，另外部分保留。舍入余数只在单 SKU 上限内继续分配；候选上限不足时，未使用金额自动转入留存。
- 未确认归因成熟度前，不执行下调或试投。
- 条件止损：仅在平台归因成熟窗口已确认或成熟数据已回溯重导后评估；成熟 ROAS 低于目标且累计 20 次点击仍无成熟归因订单时，停止新增试投。
- 条件放量：同一测试批次归因成熟、至少 3 个成熟归因订单且 ROAS 高于目标线后，每 3 天最多增加 10%，同时确认库存和售后承载。

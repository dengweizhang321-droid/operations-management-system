推广 UI 与直连共用登录保护：优先复用会话，未登录时仅在 HTTPS 淘宝登录来源的唯一密码表单中使用该店既有 Windows DPAPI 凭据。每个浏览器上下文只允许一次自动尝试；提交结果不确定也消耗尝试额度。密码不进入 n8n、参数、日志或文档。

直连推广先完成身份检查，再从只读下载列表捕获请求标识；不会因登录超时重新生成报表。既有活动清单、逐日缺失规划、导入回查与 n8n 编排边界不变。

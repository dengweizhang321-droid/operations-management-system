## 架构

BI保持跨域只读投影，不复制销售、库存或平台事实。ERP销售汇总由BI现有只读角色读取；其他领域通过固定、签名、有界的拥有方reader读取，保留真实principal与权限。目标配置归财务域，运营统计归workflow，库存统计归inventory，流量归netshop。

旧 `/api/bi/overview` 保持兼容；新接口使用独立版本，逐来源记录状态、范围、修订和截止日。未知/失败不补零、不回旧事实源。SQL最多7秒、所属RPC最多8秒、整体65秒、响应最多2MiB，跨域来源不得伪称单一原子快照。

## 当前授权与交付门槛

允许隔离开发、私有测试库迁移、只读真实来源核对及真实数据预览；用户试用反馈前不合正式实现。具体发布候选/权限与迁移影响、备份恢复准备齐备后再确认上线窗口。旧139迁移/缓存回填不重复执行；不业务补跑、发送通知或使用生产连接作开发回退。

核验包括来源合计、精确订单身份、缺数/零/负数、跨店/类目/权限、快速切换迟到响应、日历与目标独立范围、周未动活动边界、未知库存、平台加权比率、真实常用范围与读取耗时。源码自测、私有PG、真实读取与生产资格分开记录。

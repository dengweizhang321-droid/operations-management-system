## 变更

- 浏览器绑定验证后最多等待 15 秒；同一个候选页面及 URL 连续两次观察一致后才能使用，默认间隔 250 毫秒。只接受原精确吉客云 origin 或 about:blank，继续使用原登录、租户和安全验证规则，不猜选多页、不接管已打开的浏览器。
- 超时错误只记录总数、候选数、空白页数、吉客云页数和其他页数，单项最大 999999；不记录完整 URL、查询参数、fragment、页面内容或凭据。无 browser context 也使用同一明确错误类，并进入已拥有浏览器的原清理路径。
- 共享小时重试将 `API_LOGIN_PAGE_NOT_UNIQUE` 及精确吉客云 `原运行 n8n-export-first-<id> 尚未闭合` 错误归为人工处理终态。瞬态网络错误仍按原规则重试；其他工作流节点、连线、目标身份、计划和一小时等待不变。已处于等待中的旧 execution 携带旧定义，发布不能假装自动更新其快照，须单独核验与收尾。
- 原 preflight plan/apply operator 扩展为可关闭这一类 API 页面选择失败，接受旧精确错误或新版固定格式的纯计数错误。仍要求 B 节点、固定请求地址、精确节点顺序、失败状态、无成功重试或活跃执行、session_api_v1 空 exports、无 exportIntent、无未知计划字段、日期/active 匹配及四类业务效果路径全不存在。闭合须由 operator 明确执行，保留原全局锁、helper 空闲、摘要复验和 create-only 回执；并非自动清空任何失败任务。

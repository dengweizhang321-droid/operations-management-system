## 调度与时区口径

- 数据库无时区时间戳一律解释为 UTC；显式 `Z` 或偏移也转换为 UTC。比较真实时间，不按字符串字典序，不用本机默认时区。
- 展示和 cron 计算使用 `Asia/Shanghai` 的 UTC+8；独立 Windows CLI 使用标准库固定偏移，不依赖 Windows tzdata 或 Django。目录其他时区不猜测，返回巡检不可用。
- 当前目录全部是固定时分的每日五字段 cron；同时支持六字段中秒明确为 `0` 的等价格式。同一工作流多个每日时点取最近已到期的一个。
- 例：每天上海 00:10；11-03 00:09:59 仍检查 11-02 00:10 开始的窗口；到 11-03 00:10:00 切到新窗口。新窗口的 UTC 起点是 11-02 16:10:00，而不是 UTC 11-03 零点。
- 不额外引入宽限时间；恰在到期边界巡检而 execution 尚未写入时可能报漏跑。后续配置外部定时任务时避开业务 cron 的同一秒。此轮未安装调度器。
- 非当前契约的 cron（如周/月/通配步进）显式返回 `unavailable` 和退出码 2，不按日任务猜测，不静默跳过。将来目录出现此类调度时需要扩充解析及对应测试。

## 只读与有界读取

- 默认库 `C:/Users/86137/.n8n/database.sqlite`；打开前验证存在并拒绝符号链接/junction，缺失不会创建新库。
- `sqlite3.connect(database.as_uri() + "?mode=ro", uri=True, timeout=0.5)`，随后 `PRAGMA query_only=ON` 和只读事务；成功或异常均在 finally 中 `rollback()` 后 `close()`。
- 只读 `workflow_entity` 和 `execution_entity` 必需元数据；不读取 `execution_data.data`，所以不需要也不使用正则解析 flatted。
- SQL 参数绑定；目录最多 1 MiB、工作流最多 512、settings 最多 64 KiB、24h 错误最多 1000。SQLite 进度回调与最后期限检查限定约 5 秒；超限/解析失败/表缺失不输出健康结论。
- 所有真实数据库操作均为 SELECT/只读事务与 query_only。隔离测试实际尝试写入被拒绝，并比较巡检前后夹具文件 SHA-256 不变。

## 告警复用与调用方式

```powershell
# 默认与显式 dry-run 都只预览；可以从 n8n 之外直接调用。
python -B tools/n8n_schedule_watch.py --dry-run

# 隔离夹具或历史时间重现，仍仅预览。
python -B tools/n8n_schedule_watch.py --database C:/temp/fixture.sqlite --catalog C:/temp/catalog.json --now 2026-11-02T16:16:00Z --dry-run

# 仅供后续明确授权采用后的运行配置；本次没有执行此命令。
python -B tools/n8n_schedule_watch.py --execute
```

- 退出码：0=检查完成且无异常，1=检查完成且发现异常，2=巡检或提醒未完整确认。发现异常并不以进程 exit 0 掩盖。
- `--execute` 不允许同时注入历史时间、数据库或目录，避免把模拟结果误发为真实状态。
- Python 使用参数数组调用 **pwsh**，不是 powershell；无 shell 拼接。v2 载荷只有 version/kind/workflowId/code/anchorEpoch/executionId，没有收件人、自由文案或原始错误文本。
- 无 execution 的漏跑不会编造 execution ID。流程标签与提示来自发送脚本静态映射，未知流程只显示验证过的 ID。所有消息仍经 watchdog `Get-WatchRecipient` 核验本人和机器人，然后使用原 `--users` 单聊路径；无群回退。
- dry-run 调原脚本预览分支，在身份查询、账本目录创建和 DWS 调用之前返回 `local_preview, executed:false`。
- 执行模式仍使用原 sending/sent/unknown 防重账本；巡检独立 key 前缀防止与 v1 冲突。调度异常按流程/码/调度窗口去重，空绑定按上海日期去重，错误流失败按执行 ID/失败时点去重。未知投递不重放；已有 unknown 的抑制回执不阻塞其他独立发现，未确认的本次调用则停止当轮发送。

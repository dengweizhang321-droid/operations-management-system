# E2 最小实施设计（2026-11-03，候选）

本页是给执行者的设计，不是安装回执。请求 decision（Astra High），实际底层型号未独立确认。实施及检查结果以 [E2-巡检上线](E2-巡检上线.md) 为准。

## 载体及时点

复用 Windows 计划任务的 Limited/Interactive 方式，调用已存在的 runtime `pythonw.exe` 执行轻量 wrapper，由 wrapper 调现有 `tools/n8n_schedule_watch.py`。无须另建长驻服务或重新编译 launcher。n8n 自身是被监控对象，用它调度外部巡检会丢失服务不可用时的独立观察；每日一次也没有长期守护进程的收益。

拟每日上海 20:17，避开整点/半点并给当前最晚目录 cron 13:10 留出时间；派工单的“最晚 11:50”已过期。此时点不保证所有慢任务已完成，现有巡检也只检查 execution 存在性，不检查业务完成。prepare 要明确本机时区与上海绑定；Interactive 需要用户登录，不能承诺未登录仍执行。

当前只生成任务配置与安装说明，做隔离 dry-run；不 Register/Start-ScheduledTask。E1 B 候选合 main、客服四条线上与 catalog 调度一致、F1 身份链恢复之后，才进入安装步骤。当前客服线上为 09:05/09:25/09:45/10:05，而 catalog 为 12:10–13:10；用户已明确保留仓库午后时间、后续统一采用，本轮不改线上，安装前等待真实采用一致。不能为消除假警弱化判据。F1 原报告已提示身份失效，E2 不重做授权、不试发。

## 连续异常的最小防重

保留原默认 CLI、三项判据和 sender v2，新增可选 `--continuous-incidents`。原 sender 的 anchor 每日或每小时漂移，只能周期内防重，不能保证跨日持续异常只通知一次。

- 在**同一 stateRoot** 增加观察索引，键为 workflowId/code/排序去重 reasons；值只维护持续异常的 episode anchor 和必要观察信息。该索引不是发送账本，不保存或自行判断 sent/unknown；这些仍全部由原 `n8n-manual-action-alert.ps1` 的既有账本负责。
- 新 episode 使用首次实际 checkedAt 秒作 anchor；同 workflow/code 的后继 episode 保留 lastAnchor 并保证单调不重复，避免原因变化或同秒观察碰撞原 sender 不含 reasons 的 key。不改滚动 24h 查询窗口、执行计数、最新 execution 等证据。
- 在调用 sender 前原子持久化 episode，使进程中断后仍能复用 anchor。新入口用独立 watch 锁覆盖完整观察、索引更新及发送周期；不能先观察后加锁，旧健康快照会清除新事件。锁名不能与 sender 原发送锁相同，否则父进程等待子进程会自锁。sender 内部锁继续原样使用。
- 只有完整 inspect 成功、对应检查范围已观察且该异常键缺席，才结束 episode。检查不可用、索引损坏、锁忙或时间/状态异常都不能当恢复；保留既有索引并停止本轮发送。目录移除是观察范围变化，应保留旧 episode，不假装证实业务恢复。
- default dry-run 只计算预览，不写生产索引或 sender 账本；隔离演练用专用临时 stateRoot。不能扫描、改写或迁移原 sender 的历史发送记录。启用连续模式前的周期键与新键有切换边界，须说明首次安装可能形成一次新事件，不能宣称已跨历史键全量防重。
- 变化的 reasons 是新异常状态，允许新 episode；最新 execution/count 变化不重置同一错误流失败 episode。明确“恢复”仅为巡检谓词不再成立，不等于业务数据已补齐。

## 失败可发现性

wrapper 保存脱敏的 startedAt/attempt 标记、finishedAt/latest 结果、三项计数和投递结果；先写本次 started，再启动原 CLI，最后原子写完成状态。旧成功 latest 不得遮蔽更新的未完成 attempt。输出不可解析、进程异常、巡检不可用或通知失败均返回 2，不吞成成功；0 为正常，1 为发现异常且通知已确认或已 sent 防重抑制，unknown 防重仍为 2。

Status 同时展示 LastTaskResult、最后开始/完成时间、未完成标记及超过 26 小时未完成的提示。LastTaskResult 非零需人工查看；1 与 2 必须能区分。26 小时是每日计划任务的本地巡检提醒阈值，不是 helper TTL，也不意味着到时补跑业务。

这些文件和任务结果让本机人工可发现告警故障；钉钉授权断了时，它们**不能保证用户远程主动获知**。不以另一个发送器掩盖这个限制；沿用 F1 修复身份链，unknown 保留原发送账本且不自动重发。真实发送仍受独立授权约束。

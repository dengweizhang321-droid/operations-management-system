- 长 JavaScript 计时器按不超过 2,147,483,647ms 的片段等待同一绝对期限，避免超长参数被运行时溢出为立即超时；取消后不能继续安排片段。
- 保留必要有效性：有限、无损 JSON 整数，Token/时限/轮数为正，温度非负，协议与参数格式一致，输入/输出空间关系可成立。JavaScript 的有效整数表示边界不是供应商能力声明。服务端不会对供应商不支持的值偷偷裁小或失败后换参数重发。
- 本次范围为 AI 管理中的文本/视觉模型配置及网页对话。图片生成独立协议、工具权限/scope、资源体积、每项工具能力、专用经营分析阶段和外部渠道期限保持既有契约；不宣称任何任务都可无限运行。

# 净水分类口径待确认分支

2026-10-15，用户已选择“保留当前11类，逐项确认映射”。本文件据此记录方向；25项映射和交叉边界尚未批准，候选尚未激活，不直接变更在运行任务的绑定Prompt、正式字典或历史分类。见[逐项提案](current11-mapping-proposal.md)和[原答复](../evidence/classification-direction-decision.json)。

## 已确认方向：以当前11枚举为唯一输出空间

现权威 active taxonomy 与 Prompt v4 segments 完全一致，故技术修复应先去掉正文外来25标签、未替换占位符、截断JSON例子及“原价也提取”的矛盾规则。`netwater-A-current11.txt` 是适配现运行拼接器的隔离正文候选；不重复列出枚举、商品字段或JSON schema。它没有为中央净水/餐饮净水/净饮一体等重叠标签擅定新优先级，业务须先给出重叠时的边界与代表样例，才能进入正式验证和激活。

当前11类别：RO反渗透净水设备、超滤净水设备、工业纯水设备、中央净水设备、软水设备、水处理设备、自动售水机、餐饮净水器、商用净饮一体机、滤芯及净水配件、其他。

要确认的核心取舍：按过滤技术（RO/超滤）、行业用途（餐饮/工业）、安装层级（中央）、复合功能（净饮一体）同时可命中时，采用哪一个单标签；普通烧水但无净水证据的商品，以及开水器底座，是否属于本三级类目及哪一输出标签。建议由业务给每种边界至少一个正反例，不能由模型凭名称归并。

历史影响：不自动重写已确认分类。新Prompt只能创建子版本并用于之后明确绑定的新任务/验证；原任务继续绑定原Prompt。已有分类是否仍可用于price-only，应继续按当前字典资格核验。只改正文不等于旧预测已被纠正；需要另立人工复核清单。

## 未选择的历史备选：25设备类型加“其他”

本次不推进此分支；下文仅保留原方案及历史影响供追溯。若未来重新考虑，需用户另行明确选择。必须明确这是26输出类别（25条具体规则加其他），不是沿用11枚举的文案修改。先审批新字典及逐项边界，随后新建Prompt子版本、验证、激活；不在本轮自动执行。

当前25项混合功能、外观、场景，存在层级重叠：立式/柜式/步进式/轻商务/幼儿园直饮机可能同时成立；壁挂/数控/步进式开水器也可能同时成立。旧正文一些“一律”依赖图片无法观察的背部挂孔、内部管路或过滤结构，不能直接当无歧义金标标准。需业务定义固定判定优先级及无法观察时的处理。

历史影响：11→26不是一一映射。商用净饮一体机不能仅凭旧标签拆成六种直饮机；RO设备不能仅凭旧标签拆出柜式纯水机；滤芯及净水配件不能仅凭旧标签拆成滤芯/底座。必须回到原图和人工证据重新复核；保留旧分类、旧字典版本与来源，不就地覆盖。新字典可能使旧分类不再合格，从而减少原price-only复用、增加完整识别需求，影响量需权威历史分布后量化。

## B类价格专用候选

`netwater-B-price-only.txt` 是供未来候选拼接器评估的文字方案，不替换现行 `priceOnlyAnnotationPrompt()`，不向正式Prompt保存。必须由调用器提供唯一合法固定segment，并复用当前统一价格规则和严格schema。现B类已经不发送A类正文，因此缩减A正文不会使B类获得相同收益。

## 访问与实现

- 新视图：`http://127.0.0.1:3100/?module=shop&view=outlets&overviewView=balanced&period=custom&from=2026-09-01&to=2026-09-28`。
- 旧视图：同一入口移除 `overviewView=balanced`；默认、旧书签与非法模式均为旧视图。两视图按活动模式挂载，旧 ERP 接口及净额、毛利、退货、原平台范围保留。旧平台与店铺选择独立保存。
- 3100 是私有 SQLite **合成夹具预览**，GET/HEAD、外部连接与提交限制沿用原启动器。不能把截图中的合成金额当作实际经营数。
- 新增 `GET /api/netshop/store-overview`，由 Django owning reader 聚合。原 `/api/netshop/overview` 仍是数据集元信息，语义不变；未新增迁移、writer、导入来源或第二 authority。
- 组件位于 `app/netshop-overview/`，类型与 decoder 位于 `lib/netshop/store-overview-contract.ts`。抽取共享 `StatisticalPeriodPicker`，复用 shell 日期与 URL 合同；近几天/几月的滚动意图、本季意图与自定义同日期范围可区分，前进/后退、刷新和模块导航保留状态。
- 所有金额按整数分传输；万元除以 1,000,000。比率为未乘 100 的小数；费率可超过 100%；费率/转化率比较为百分点；ROAS 为倍数。前端只格式化，不负责经营聚合。
- 首包包含五卡、完整有界日序列、趋势、分页明细及一页店铺摘要。只展开一家店加载详情；取消旧请求并以 generation、请求键、overviewToken 与 scopeKey 防止迟到与混版。源 revision/manifest 前后核验，有界重读；在途权限变化在边缘重新鉴权并拒绝释放旧范围。

# Pi 对话集成与真实模型验证

日期：2026-10-18。基线 `25fe1fa3`，独立工作树开发，未改用户主工作区。用户明确授权使用系统现有 OpenCode 额度完成真实验证；生产切换须等用户另说“上线”。

## 本次现象与修改

只读正式账本显示最近两次 Pi 操作均 succeeded，最新一次完成 19 次模型调用、28 次系统工具调用并生成 XLSX/Markdown。实际浏览器也能读到最终中文答复和下载链接，但截图停在最早英文进度：原 Pi 不会跟随新结果滚动，环境 idle 统一显示“就绪”，结果与附件埋在长记录底部，难以判断是否完成。通过原网页下载既有 XLSX，验证 ZIP、全部 XML 与四张工作表有效；这不等于逐项经营结论准确性审计。旧 unknown 操作保持原状态，未重放。

- Pi 移到“AI 对话”，输入区提供 **Chat / Agent** 切换；复用原主导航、AiWorkspaceHost、Chat 和 Pi 控制器及样式。两种模式独立保留草稿、会话、请求和权限，切换只改变可见性，不卸载运行控制器；按模式隔离渲染错误。原“Agent 工作流”继续提供原工作流。
- 完成状态按操作终态显示，任务完成横幅直接提供本轮产物下载和“查看分析结果”。历史附件保留在来源区域，不冒充本轮产物。事件分页尚未恢复完时不把早期进度标成最终结果。
- 新消息默认跟随到底部；用户向上阅读后停止跟随，切换模式继续保留位置。修正了 Markdown 异步排版产生的 scroll 事件被误当用户离开底部的问题。
- 环境列表使用最新操作状态，首次提问生成简短标题；更换范围时以新问题生成新标题，避免带出旧范围题目。网关默认要求中文进度、最终答复及来源/截止日/口径/缺口，文件名与用户下载入口说明明确。

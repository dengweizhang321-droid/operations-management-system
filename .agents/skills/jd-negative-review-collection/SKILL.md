# 京东差评收集

## 先读资料

1. 手册：[京东差评收集](../../../docs/自动化/京东/京东差评收集.md)，含完整步骤、页面接口、判定规则和踩坑记录。
2. 店铺注册表：`config/jd-store-accounts.json`（店铺键、店铺名、shopId、profile、CDP 端口、下载目录）。
3. 串行与登录约束：[京东多店铺账号切换与串行执行手册](../../../docs/自动化/京东/京东多店铺账号切换与串行执行手册.md)。

## 核心流程

1. **确定范围**：店铺集合、销售排行口径（默认近 30 天 SKU 交易额前 20）、评价时间窗（默认近 12 个月）、每商品评价条数（默认最新 20 条）。
2. **取销售排行**：用运营系统 netshop 接口 `/api/netshop/product-performance`（`dimension=sku`、`platform=京东`、`outlet=京东\u001f店铺名`）翻页取数，本地按 `transactionAmountCents` 倒序取前 N。数据截止日期以接口返回的 `dataCutoffDate` 为准。
3. **逐店串行采集**：
   - 按注册表启动该店独立 Chromium（独立 profile + CDP 端口），一次只开一个；
   - 先到 `https://shop.jd.com/jdm/home` 读页头店铺名并展开店铺信息核对店铺 ID，与注册表不一致立即中止；
   - 打开 `https://wares-jdm.jd.com/ware/goodsAppraise`，重置筛选 → 批量粘贴 SKU（逗号分隔）→ 设日期范围 → 查询；
   - 点“导出查询评价”→“导出”→ 进“导出记录”轮询“刷新”至“已完成”→ 点**第一行（最新任务）**的“下载”，用 Playwright `download` 事件落盘。
4. **采集商家回复**：对差评逐条筛选该 SKU + 当天日期，在列表行内点“查看回复详情”，捕获 `CommentResourceService.getCommentById` 响应，取 `replies`，并过滤掉 `nickName` 以 `jd_` 开头的用户追问，只保留商家回复。
5. **判定差评**：京东评价等级 `1`（1 星）为差评，`2` 为中评；按 SKU 分组、评价时间倒序取最新 N 条，逐商品统计。
6. **交付**：HTML 报告（KPI、四店逐商品表、差评卡片含回复、可展开的评价原文）+ Excel（汇总 / 评价明细 / 差评清单含回复 / 无评价商品 / 全部导出评价）。

## 硬性约束

- **一次只运行一个店铺浏览器**：四个 profile 共用同一 `userDataDir`，同时启动后续实例会直接退出；切换时先结束上一实例的进程树再启动。
- **身份先核对再采集**：只认页头店铺名 + 店铺信息里的店铺 ID；Profile 1 可能停留在同账号的另一家店，必要时访问 `https://shop.jd.com/jdm/shop-switch` 切回注册店铺后再核对。
- **导出必须取第一行**：导出记录按时间倒序，点最后一行“下载”会拿到历史任务的文件。
- **评价按 SKU，不按 SPU**：同款不同规格评价互不通用；商家后台评价管理也不能用 URL 参数直达 SKU（`?skuId=`、`?sku=` 实测无效），SKU 只能粘进筛选框。
- **无评价商品单列**：查不到评价记录的 SKU 不能算“无差评”，输出时必须标注“无法判断”。
- **只读**：不回复、不投诉、不改评价、不提交任何写操作；需要人工处理时停下来说明，不代替运营操作。

## 故障处理

| 现象 | 处理 |
| --- | --- |
| 启动第二个 profile 后端口无 CDP | 先结束上一个实例（`taskkill /PID <主进程> /T /F`），确认端口释放后再启动 |
| 页头店铺与注册表不一致 | 到 `shop-switch` 切换后重新核对店铺 ID；仍不一致则中止，不采数据 |
| 下载事件没有触发 | 检查是否点到了历史任务；确认已切到“导出记录”页签且状态为“已完成” |
| 抽屉/弹窗遮挡点击 | 点 `.jd-drawer__close-btn` 关闭，再操作；不要用 force 点击绕遮挡 |
| 日期筛选没生效 | 输入后按 Enter，再点空白或 Escape 收面板；用“共 N 条”和导出弹窗里的“评价时间”双向核对 |
| 导出条数超 3000 上限 | 缩小日期窗或拆分 SKU 批次，禁止只导一部分却当作全量 |
| 登录失效 / 出现验证码 | 停止，交人工登录或安全验证；不重试、不换凭据 |

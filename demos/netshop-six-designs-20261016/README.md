## 使用边界

- 九栏为本次候选目标结构：店铺数据、商品数据、企业购分析、推广分析、推广调整、客服分析、自营数据、商品信息、系统配置。主导航及绿色主题参考本项目实际 `app/shell/` 与 `app/styles/tokens.css`；候选不是正式 React 组件接线。
- 推广调整保留总览、计划与词、智能托管、计划建设、策略与复盘、设置。维护与空态页面采用适合业务的表单、资料区及空态，不强制生成经营图表。
- 搜索文本按 Enter 确认，中文选词 Enter 不提前提交；店铺、时间、页签、明细展开、对象详情、列设置、示例 CSV 导出、本地草稿可操作。
- 所有业务数值、记录编号、店铺及客服身份均为合成示例。原型不读取生产 API、不执行真实授权、同步、导入、托管或外部发送。
- 企业购、自营以及本次推广样例仅提供示例自营范围。其余范围禁选，不以换标题冒充数据变化。
- “保存”只在当前文件会话保留草稿，刷新即恢复。布局方案尚未由用户选定，未修改正式系统页面。

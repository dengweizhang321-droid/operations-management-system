## 本轮五项内容调整

1. 目标：独立的整年/整月目标及当前累计、完成率、与时间进度差。年度同比用去年同日累计，年度进度环比为较上月末的百分点变化；月累计环比用上月同日期、同比用去年同日期。未知或无目标不计算完成率，未设目标店铺从完成率分子分母排除。
2. 待处理：仅运营事务，工作计划/新品上架各按已逾期、未来7天到期、连续7天无进展分组；已完成/取消排除，同一事项可命中多组，关注总数去重。预览今天10月5日，临期含今天至10月11日，无进展含9月28日及之前。
3. 销售：增加客单价，定义为ERP净销售÷同范围可信ERP订单数；原流量与转化区替换为各店净销售同比下滑。同比<0列出，默认≤-10%重点关注、≤-20%严重；阈值为演示规则，正式采用前可调整。缺失、零或负基期不能直接判异常。
4. 类目：全部三个ERP类目，本期净销售、占比、同比增减额、同比及环比，支持详情；类目合计与销售总览一致。
5. 广东仓：无可用库存、紧急补货、补货预警、低周转、数据待校验，点击看型号明细；复用现监控规则的生产周期/安全天数逻辑，缺销量或生产周期保持未知。

注意：现销售分析旧 `averageOrderValueCents` 实际为剔除配件净销售÷净销量。新版的每单净额不能不经映射就直接接这个字段；已有可信ERP订单读取协议可作为正式接线依据。预览订单身份和年/月目标都是合成事实。

用户在流量表“店铺”表头处提出选择平台与店铺相互切换。流量区现有平台、店铺两个联动选择框，以及“按平台 / 按店铺”表格维度。平台行可点击进入该平台店铺；店铺行可点击选择单店。换平台清除原店铺，选店铺匹配所属平台，重置回当前全局范围；刷新保留选择。

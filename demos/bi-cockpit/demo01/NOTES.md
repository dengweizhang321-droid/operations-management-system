# Demo 01 · 均衡经营总览

信息顺序：经营结果与同口径目标 → 三项优先关注 → 趋势与店铺贡献 → 商品与推广 → 公司库存与完整财报月 → 质量及专业入口。固定分区保持日看全局；局部排行、筛选、详情使用统一共享交互，不另造计算。

## 真实案例调研

2026-10-05 实际联网读取 Shopify 官方文档：
- https://help.shopify.com/en/manual/reports-and-analytics/shopify-reports/overview-dashboard/using-the-overview-dashboard
- https://www.shopify.com/analytics （官方检索结果核验，未逐段打开）

原 overview-dashboard 基础地址首次打开工具返回 Internal Error；经官方域搜索发现 using-the-overview-dashboard 子页并成功完整读取，未把首次失败记成访问成功。

具体借鉴：顶部统一日期与比较范围；经营指标与趋势卡片先行；少量经营观察引导查看关联报告；来源延迟/缺数在读数处提示。官方文档说明对应内容位置为 quick filters、metric display、data disruptions 与 insights。

适配理由：TERUISI 的日常经营需要先判断公司整体表现，再进入现有专业模块，这与 overview → associated report 的层级吻合。

适配内容：改成 TERUISI 有效品牌绿、顶部导航与语义字号；复用当前双月日期组件；新增公司库存独立快照和销量窗口、完整月财报与同口径目标；不复用 Shopify 实时刷新、访客去重或订单归因定义。ERP、平台、广告归因和财报始终分开。只借鉴组织与交互，不拷贝产品源码、图像或文案。

## 交互与边界

四个阅读跳转、三项关注跳转、四个专业模块按钮均使用共享 data-action。七域完整内容由 shared ui 生成；区块内店铺/商品/风险详情及关闭保留过滤状态。所有金额来自共享 model，版式不重算业务。

推广投入提示仅在当前推广完整覆盖时生成比较观察；缺数时说明已覆盖值不代表全店效率。公司库存与财报不随日期/店铺筛选伪装历史分摊。

## 比较

适合每日快速浏览，路径直接，正式实现复杂度低至中。优势是全量经营内容一页可见；代价是长页和多张表，跨对象系统性比较与原因探索弱于 Demo 03/05。1100px以下分区单列，390px局部表格横滚，字号保持。

# 网店分析三版本整合稿

2026-10-16，用户在三版本比较讨论后要求“出一份HTML看看”。交付 [netshop-integrated.html](netshop-integrated.html)，全部样式、SVG、脚本与合成数据内嵌，可单文件离线打开。

- 保留现有五栏目职责：店铺分析、网店总览、平台对比、商品表现、推广分析。
- 重点实现店铺 → 商品 → 同商品推广 → 返回的连续查看，保留同店、期间、维度和返回时的明细状态。
- 店铺分析采用经营摘要、六项指标、趋势/变化双栏、商品明细、贡献与关联状态的顺序。
- 商品表提供销售、流量、推广列组及列偏好；搜索和关注只筛明细，顶部仍为整店摘要。列偏好存储不可用时仅在会话内保留，并明确提示。
- 推广计划、单元与关键词分开，关键词是示例子集；未知成本不判保本，平台成交和广告归因成交不相减推算自然成交。
- 完整、部分缺日、无数据、失败及同期未提供有不同状态。共性口径集中到可展开区域，指标旁保留必要限制。
- 所有店铺、货品、数值与结论均为合成演示，不读取生产、不调用模型、不执行真实推广或业务写入。

重建：`node demos/netshop-integrated-20261016/build.mjs`。

验证：`node demos/netshop-integrated-20261016/verify.cjs <本机jsdom模块目录> <结果JSON路径>`。

92项无网络DOM断言通过，含SKU/SPU汇总守恒、图表/KPI一致、跨页返回、搜索/中文输入法、不可比导出与零日覆盖未知状态。详情见 [任务报告](../../docs/netshop-integrated-20261016/REPORT.md)。浏览器工具先前明确拒绝 `file://`，本轮没有绕过；Windows文件文档URL只在JSDOM中核验，没有原生浏览器像素、布局或响应式尺寸实测。

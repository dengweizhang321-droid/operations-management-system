## 观看

直接打开 `index.html`，或在本目录启动纯静态回环服务：

```powershell
python -m http.server 3196 --bind 127.0.0.1
```

打开 `http://127.0.0.1:3196/?layout=1`。顶部切换五种布局；`layout=1..5` 可以直接定位。3196 仅由本次静态设计服务占用，不启动 Django、Worker 或数据库。

## 演示内容与边界

- 五版都可查看5.1—5.8的设计组织；平台/店铺/日期、日/自然周/自然月、环比、同比缺源、店日覆盖状态联动。
- 所有数值均为本目录合成夹具，覆盖示例2026-08-01至09-29，非真实店铺经营数据。`DEMO-R1` 是样例版本，不能当生产revision。
- 京东标注总订单金额/总订单行/跟单SKU；天猫标注推广净成交/净成交笔数/商品ID。归因窗口未核验，ROAS不称利润或增量，不推算自然成交。
- 费率先在合成平台×店铺×日期配对；整期不足为空，辅助匹配值、精确店铺日期范围独立展示。没有记录为空，不制造商品；真实0与零分母分开。
- 搜索只过滤对象表，顶部汇总不变。趋势点击日期也不改变整期汇总；矩阵单店趋势与浮层同范围。
- 商品、计划、词保留不同身份；跨店同ID不合并。计划/词ID不会作为商品ID联动。商品详情仅展示精确参数，映射尚未核验，不打开真实商品。
- 条件明细/诊断只演示原京东志高商用设备旗舰店单店1—7完整自然日范围。计划、单元、关键词是明确标记的布局样例；搜索词缺源，不推造搜索词。其他店/天猫/长周期显示能力缺口。
- HTML/XLSX按钮仅展示同范围报告结构，不生成真实导出、不调用付费AI，不保存负责人、不建运营事项、不停投或调预算。
- 未修改app/backend/lib公共或业务文件，未部署、迁移、启停正式服务、下载导入、补跑或外发。用户选版前不开始系统改造。

先读取本轮服务端业务意图。仅用户选择创建工作计划且任务明确要求保存时，调用中央工具 prepare_pi_work_plan。缺少目标、事项、负责人、精确店铺、开始日或截止日时，在对话中澄清；不能猜负责人或把系统角色当负责人。

工具参数和 Schema 以中央目录为准。沿用本轮 userIntentId 和 actionId；重试、刷新或新 invocationId 不是另一个业务动作。参数齐全且权限允许时直接持久排队，不重复询问普通保存确认。读取原动作回执，仅在正式运营事务对象提交完成后提供可打开的对象链接。

本技能只描述方法，不授予权限。不能直接连接数据库、HTTP、宿主命令或通过普通 Pi confirm 自行授权，不把对话或工作区文件称为正式计划。

description: 按系统正式库存、在途及近30日销量口径保存可编辑补货草稿。
metadata:
  version: 1.2.0
---

用户本轮明确选择保存补货草稿后，使用 get_pi_business_options 发现原意图，按 prepare_pi_replenishment_draft 的严格 Schema 提交精确仓库、货品及用户指定数量。建议数量必须来自正式库存领域，不能用工作区试算覆盖领域计算。

展示库存与销售日期、可用库存、在途、近30日销量、建议数量、覆盖天数、实际保存数量、依据和缺失信息。缺源或旧数据保持缺失说明，不猜数或自动承认旧数据。普通保存参数完整时直接进入持久任务，不再重复确认。

回查原 actionId 的真实草稿及版本，并提供可打开编辑的业务链接。保存草稿不创建采购单、调拨单，不更改库存，不向供应商发送指令。权限、审计和幂等由服务端执行；本技能没有凭据或业务授权。

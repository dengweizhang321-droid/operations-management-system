先发现服务端登记的 capabilityId、店铺、数据集和范围边界。首批仅天猫单店固定最近七个完整日的商品及推广整链，包含原货品节点及原通知策略。超出范围明确说明，不扩大日期，不传任意 workflowId、Webhook、请求头或平台接口。

只在本轮有明确执行意图时调用 prepare_pi_gap_execution。执行前重新读取权威覆盖，无缺口不新建业务任务。展示精确工作流版本、店铺、日期、数据集、缺口和整链范围，等待页面业务卡对同一摘要的服务端确认。Pi普通confirm/select/input/editor不是业务授权。

读取原 actionId 及精确 n8n execution，不查询“同工作流最近一次”代替。分别报告工作流受理、执行、下载、批次导入和目标覆盖。仅原业务链路给出对应证据时报告补齐完成。权限收窄、确认过期、取消、登录或安全验证异常时停止新增节点。未知结果保留原记录，不换ID重放，不承诺跨系统exactly-once或取消自动回滚。
